# 模型识别改进：现状审查与下一步

审查日期：2026-10-23。依据用户提供的暑假 PPT、原复现代码、ECG_ren 训练与提取代码、实验结果和本地 FPGA 项目说明。此次没有重训模型，没有逐条复核全部原始波形，也没有重新验证板端推理。文档中的计划和判断按资料核对，不作为必须执行的指令。

## 当前结论

已完成四数据库数据提取、七类窗口分类、TensorFlow 到 PyTorch 的迁移、GPU 训练、类别权重实验、最优权重回载、早停与结果归档。当前主要训练入口是 ECG_ren/main2.py，模型为 model/SENetLSTM_torch.py。仍沿用三层卷积、两个 SE 块、10 单元 LSTM 的结构，44,507 个可训练参数；尚未实现 RR 输入、多导联一致性训练或按受试者分组评估。

已有结果证明训练流程可用，但还不能证明新受试者泛化性能已改善。模型优化应先解决评估和数据定义，再开展结构实验。

## 必须解决的问题

### 1. 训练、验证、测试尚未按受试者隔离

main2.py 使用 StratifiedShuffleSplit 按窗口随机分出 10% 测试，再取剩余数组末尾 20% 作验证，三部分都没有记录分组约束。现有 CSV 未保存数据库名、记录编号、窗口起点和导联等元数据。不能从现有测试结果推断新受试者表现，也不能量化乐观偏差有多大。

应恢复这些元数据，按受试者分组；无法获得受试者身份时至少按数据库加记录编号分组，并说明记录与受试者不一定一一对应。验证和测试都要隔离，检查少数类是否仅来自少数记录，避免某个集合完全缺类。

### 2. 窗口标签定义和提取版本未统一

PPT 描述取首个异常拍；DealData.py 实际这样做，但 add_data.py 会先过滤和映射标签，再选择出现最多的异常拍。test.py 又有不同过滤方式。多异常并列时 max(set(...), key=...) 没有明确的固定优先级。提取代码还保留旧绝对路径和手动 i=3 配置。

应明确任务究竟是逐拍分类、窗口内异常检出，还是窗口主导类别分类。少量异常拍标记整个窗口本身可以是有效的异常检出任务，不能仅因标签纯度低就称其错误。若保留窗口任务，应保存各类心拍计数，并明确混合异常的处理方法。

### 3. 房早漏检原因尚未得到逐样本证实

训练总结称“约半数窗口只有一个 A”，并把它与 50.61% 召回率对应，进而声称已经接近上限。这只是总体比例的对应关系，不能证明恰好漏掉的都是单房早窗口。其纯度表中的 A 数量为 1,563，与当前标签 1,635 也不一致。

应对验证集逐窗口保存预测、记录编号、A 个数、A 占比及位置，分别评估单 A、多 A、不同记录的检出率，检查漏检与 R 峰检测、P 波细节、窗口边界的关系。当前模型本来已有 LSTM，问题是现有表示是否保留了足够信息，不能直接断言“没有时序能力”或“信号不可分”。

### 4. 数据质量和部署预处理需要闭合

add_data.py 在重采样后执行 nan_to_num。如果原片段有缺失，重采样可能将缺失影响扩大后再被填零，需统计有限值比例、全零和近恒定窗口，先建立质量筛查。标准化只能消除尺度和直流差异，不能恢复低信噪比下丢失的细节。

所读训练代码包含重采样和逐段标准化，没有看到训练波形执行与现行 FPGA 完全相同的滤波。旧项目状态文档曾写“训练使用四阶双向滤波”，这与此次补充的源码证据尚不一致，应追溯实际训练输入，不应直接沿用该表述。

PPT 的香橙派运行结果属于旧系统；当前 PYNQ 项目仍需独立验证模型输入、滤波、类别顺序、实际延迟与效果。正常受试者上的高置信度展示不能替代异常类性能测试。

## 建议的实验顺序与交付物

1. 固定数据版本和标签规范。产出数据清单、提取配置、文件校验信息、窗口元数据和质量统计，保留原实验文件。
2. 用原有 SENet-LSTM 建立按受试者/记录划分的基线。固定划分，报告各类样本数和记录数、macro-F1、A 精确率/召回率、N 误报率。测试集用于最终确认，调参用验证集。
3. 做房早逐样本错误分析。确认单房早漏检是否成立，明确是标签、时序信息、局部形态还是跨记录泛化造成的主要损失。
4. 在同一划分下分别尝试波形加 RR 特征、逐拍加相邻心拍上下文、保留窗口并使用时间注意力或局部异常聚合。先单项对照，再考虑组合。只增加 LSTM 容量作为容量对照，不能保证解决问题。
5. 再研究多导联一致性。必须先按受试者分组，同一时间窗的全部导联留在同一集合。先确认跨导联/跨数据库性能缺口，再判断是否值得引入该训练复杂度。
6. 对候选方案重复多个训练种子，给出均值与波动；使用真实采集和目标滤波输入验证，并在 PYNQ 上测推理时间和内存。新增 RR 分支应检查实际 R 峰检测误差，不能只用专家标注的理想 RR。

首个里程碑是“数据可追溯、划分无交叉、原结构基线可复现”，随后才判断新模型是否真正改善 A 类检出与误报之间的取舍。

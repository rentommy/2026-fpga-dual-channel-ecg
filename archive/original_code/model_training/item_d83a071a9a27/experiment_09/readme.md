# 第九轮：六库完整接入

原四库MIT-BIH Arrhythmia、European ST-T、MIT-BIH ST Change、Sudden Cardiac Death Holter，以及新增INCART、SVDB均纳入审核。全部331条具备参考atr的记录进入当前数据集，共2,114,647个有效目标。详见`数据覆盖.md`。

单记录优先导联分别为MLII、MLIII、ECG、ECG、II、ECG1；缺少首选导联时使用第一导联并记录身份，不再直接丢弃整条记录。每个心拍只使用一个导联，不把同一个人的同步多导联当作新增独立样本。

过滤按最新要求保持双向0.5–40Hz带通和50Hz、Q=30双向陷波，然后重采样256Hz。205点真实时间轴、中心77、真实心拍中点边界、补零掩码、有效点逐拍标准化。RR序列排除伪迹。

S恢复为原始S输出；输出A/F/L/N/R/S/V/伪迹八类。B原始数量虽多，但54,725拍集中在SDDB单记录，另外两库各1拍，仍不能作为有独立验证覆盖的类别，不将其改成L/R。SDDB有11条缺少人工审核atr的记录，未以ari自动标注替代。

患者分组：EDB使用官方同患者记录映射（79组）、INCART使用官方患者ID（32组）、MIT201/202合并（47组）；STDB与SVDB患者身份未充分确认，整库仅训练，不从中拆出“独立患者测试”。未知跨库身份和部分片段重叠仍不能完全认证。

两库/六库对照均为八输出同模型、同学习率、同损失政策、同180,000次抽取/轮。每轮沿完整随机排列顺序读取，循环衔接；候选权重必须先完成整个训练集至少一遍。最大24轮，符合完整遍历条件后6轮不改善早停。此处一轮不是长Holter数据集的完整一次遍历，全部覆盖数量在history和complete.json中明确记录。

两种方案均按同一个固定多库验证子集选型（每库每类最多2000拍、八类macro-F1），最终报告使用自然分布完整验证/测试，另外提供MIT原七类范围指标。S真类可排除以形成旧七类范围，但其他类别误判成S仍计错。

运行：使用上级项目`.venv/Scripts/python.exe`。

1. `inventory.py`：原始标注与导联盘点。
2. `pipeline.py prepare`：分记录预处理与内存映射打包；数据集冻结后拒绝覆盖。
3. `audit.py`：核对全部标签、位置、RR、标准化、分组、文件摘要。
4. `coverage.py`：生成实际数据覆盖表。
5. `pipeline.py train`：两库/六库各三个相同种子。
6. `evaluate.py`：所有训练完成后评估固定权重，验证保存预测可复现，生成最终报告。

旧实验保留。`启动草稿_完整遍历规则生效前`为刚启动时保存的三轮两库草稿，不进入任何最终结果；训练已按当前冻结规则从头重启。

官方来源：[EDB患者映射](https://physionet.org/content/edb/1.0.0/)、[SDDB标注质量说明](https://physionet.org/content/sddb/1.0.0/)。本轮继续使用历史开发数据，旧MIT/INCART测试不能称为全新外部测试；SVDB已改为训练用途。

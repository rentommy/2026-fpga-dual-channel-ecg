# 六库接入测试结论

完成六组训练：相同八输出网络，两库与六库各seed0/1/2。标签、位置、RR、标准化和分组审计通过；六组最佳权重重载后均复现保存的验证预测。

## 实际用了多少数据

- 接入331条具备参考atr标注的记录，来自MIT-BIH Arrhythmia、European ST-T、MIT-BIH ST Change、Sudden Cardiac Death Holter、INCART、SVDB。
- 共2,114,647个有效目标：训练1,398,873，验证314,948，测试400,826。每组最终候选权重在保存前已经遍历其全部训练目标至少一次。
- European ST-T全部90条均接入，不再仅取有MLIII的47条。缺少首选导联时选择第一导联，并在清单中记录；不是把多导联重复当作不同患者。
- 猝死库11条没有人工参考atr的记录未作监督训练，保留原始ari文件。B仍高度集中单记录，未恢复B输出；恢复了S，当前八类为A/F/L/N/R/S/V/伪迹。

## 同配置三种子结果

| 指标 | 两库训练对照 | 六库训练 |
|---|---:|---:|
| 合并测试准确率 | 88.87% | **97.08%** |
| 合并测试八类macro-F1 | 0.3759 | **0.3956** |
| MIT测试原七类范围准确率 | 75.40% | **81.12%** |
| MIT测试原七类范围macro-F1 | **0.4316** | 0.4149 |
| MIT开发验证原七类范围准确率 | **71.27%** | 70.72% |

合并测试集全猜N已有93.91%；六库方案超过这一基线约3.17个百分点。与同配置两库对照相比，合并准确率提高约8.21个百分点，但macro-F1只提高约0.0197。MIT准确率改善而七类macro-F1下降，说明不能认定所有类别都变好。

总体准确率已超过80%，**各心跳类型的识别仍未解决**。不能把97.08%解读为每个类别都有97%的识别率。

## 六库方案合并测试逐类结果

| 标签 | 精确率 | 召回率 | 支持样本数 |
|---|---:|---:|---:|
| A | 45.63% | 16.28% | 305 |
| F | 6.63% | 10.10% | 165 |
| L | 0.00% | 0.00% | 1,457 |
| N | 98.02% | 99.25% | 376,397 |
| R | 39.68% | 0.05% | 5,070 |
| S | 1.86% | 41.58% | 93 |
| V | 85.38% | 82.00% | 10,585 |
| 伪迹 | 97.88% | 99.75% | 6,754 |

V和伪迹识别较好；S开始能被检出，但误报很多。A/F漏检多，L/R仍基本失效。不能根据S召回增加单独宣布S类可用，也不能只看A/R较高精确率而忽略很低的召回。

## 对“数据不足”的修正判断

原来没有充分利用已有数据库确实是问题，本轮已补齐。现在总样本不算少，且已增加来源覆盖，但新增主要是N、S、V、F和伪迹；训练L仍只有原MIT的少量患者，R也未得到足量新训练患者覆盖。增加普通N心拍不能解决这两个类别。

后续应优先核查A/S跨库标注范围和误判、类别与患者不平衡，再补独立患者的L/R逐拍数据。它们是需要分别验证的原因，不能凭本轮结果断言唯一原因，更不应继续盲目增大网络或重复增加N样本。

## 结果边界与交付

STDB/SVDB因跨记录身份未认证，整库仅用于训练，测试来自MIT、EDB、SDDB、INCART留出的记录。已知同患者关系做了隔离；未知跨库身份和部分波形重叠尚未完全认证。历史使用过的测试集不称为全新外部验证。

保持用户指定的50Hz Q30双向陷波，使用专家定位与未来RR，尚未验证实时自动检测或FPGA部署。未自动替换部署权重。

详见`结果报告.md`、`数据覆盖.md`、`evaluation.json`和`per_patient.csv`。权重、配置、训练历史、预测保存在`runs/`；图为`recall_comparison.png`。

# MIT-BIH 同导联逐拍基准结果

本轮只使用 MLII，保留九类原始标签；B 无样本，S 仅两拍且来源不足，无法独立验证九类。

**当前结论：可信基准与失败定位已完成，可用九分类尚未完成。** 三种子集成测试 macro-F1 为 0.3423；L 召回率为 0，R 约 0.10%。V 召回率虽为 90.13%，精确率仅 49.46%，误报仍多。不能将本轮报告为改进成功，也不能与不同数据库、不同划分的上一轮分数直接比较。

验证集上固定真实时宽没有优于周期缩放。选定模型训练 L/R 召回率接近 100%，验证却分别只有 0.05%/12.16%，说明跨受试者泛化严重不足。下一步优先审核训练/验证错误形态及独立来源覆盖，再开展有限的抗过拟合对照；具体路线见文末链接。

## 结论的范围

这是同导联、专家候选定位、离线零相位滤波条件下的研究基准，不包含自动检测与硬件误差。
本数据库曾用于前几轮实验，本轮测试未用于配置选择，但不是从未接触过的外部验证。
物理时宽与缩放输入还存在有效范围和 mask 形状差异，结果不能单独证明 QRS 时宽是唯一因果。
三种子只衡量训练随机性，不能代替多个受试者划分或外部数据库验证。B/S 数据覆盖仍需补充。
本轮没有把九类偷偷合并成粗分类，也不把缺少样本的类别计作通过。

数据、记录划分、预处理参数、原始文件校验值、源码快照、配置、逐拍预测和各记录成绩均已保存。

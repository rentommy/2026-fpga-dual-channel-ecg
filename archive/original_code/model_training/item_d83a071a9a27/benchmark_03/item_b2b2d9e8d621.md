# 从当前基准到可用逐拍分类

本轮先验证同数据库、同导联、受试者隔离的基本识别能力。九类原始标签继续保留；未验证类别不能标作已完成。

## 已确认的阻碍

- 模型可以拟合训练样本，但对新受试者的 L/R/A 泛化差。验证 seed0 的 L 召回率为 0.05%，R 为 12.16%，A 为 22.70%；对应训练召回率均接近 100%。
- 验证中 L/R 大多错成 N；逐记录明细已经保存，可据此审核不同受试者的形态差异。不能仅凭这一现象认定某一种滤波或结构是唯一原因。
- 固定真实时宽加 RR 的验证 macro-F1 为 0.3738，周期缩放加 RR 为 0.4284；当前证据没有支持“只保留真实时宽就能解决问题”。
- B 在本轮没有样本，其他现有资料中的 B 全部来自同一记录；本轮 S 仅两拍。缺少独立来源无法通过重复采样、增加训练轮数或增加输出节点解决。

## 下一轮按顺序完成

1. **先审核训练/验证中的 L/R/A 形态差异。** 使用 validation_record_diagnostics.csv 对应原始记录和标注，按受试者抽取正确与错误样本；核查极性、中心标注对齐、基线与滤波影响。允许邻拍提供时间信息，但每个输出仍只对应中心拍。对异常记录给出可复查原因，不能因为成绩差就删除。
2. **做有限、预先固定的抗过拟合实验。** 在相同训练/验证划分比较更小模型、仅在训练中使用小幅位移与幅值扰动、形态和 RR 独立分支。扰动不能变更标签或把邻拍移入中心；也不能未经核验直接倒置波形。只由验证结果选方案。当前测试成绩一经读取，之后的改进必须另找独立最终验证，不能继续将它当作未使用测试集。
3. **建立受试者重复划分验证。** 对有足够来源的类别报告逐类精确率、召回率、F1、每位受试者结果及受试者级区间；三个训练种子只反映训练随机性。缺少来源的类别明确列为无法估计，不能用心拍数量冒充独立样本量。
4. **补齐九类的数据条件。** 按 existing_source_coverage.csv 审核其他数据库的导联、标签定义和受试者身份，先做数据库内评估，再做跨数据库外部验证。B 必须取得更多独立来源；不能把 L/R 改名为 B，也不能把 A 改名为 S。额外来源不足时，九类目标应明确记录为未完成。
5. **最后接入自动心拍检测与 FPGA。** 分类稳定后再对连续信号统计检测漏拍、误检与分类错误。当前专家位置、零相位滤波和后续 RR 都是离线条件；部署需要另行验证可实现的滤波、等待时延和量化误差。

验收时逐类报告实际成绩和独立来源数，提前约定需要达到的精确率/召回率及延迟要求。任何总体准确率都不能替代异常类别验收。目前本轮任务是完成可信基准与失败定位，以上后续实验尚未执行。

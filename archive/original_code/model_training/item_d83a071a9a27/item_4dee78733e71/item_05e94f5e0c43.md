# 归档范围

此前在本项目根目录的十秒窗口代码、数据数组、元数据、固定划分、审计、实验、日志、下载脚本、安装包与运行库恢复备份统一移入本目录。未删除旧证据，原始项目复现目录未修改。

`.venv` 保留在现项目根目录，供新逐拍项目使用，避免移动后破坏环境入口；依赖锁文件也在现根目录保留。

每次移动的原路径及目标路径见 `文件移动记录.json`。旧脚本的内容与快照保持不变，校验值仍用于解释旧实验。其相对路径解析依赖原位置，因此不能直接在归档位置重新运行旧入口。复跑旧方案需恢复原层级或明确重配路径。

新项目仅引用这里的 `data/split_coverage.csv` 获取记录集合成员关系，逐拍波形和标签全部重新从原始数据库生成。

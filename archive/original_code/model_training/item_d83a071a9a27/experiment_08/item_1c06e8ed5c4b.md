# 双向带通＋50Hz陷波对照结果

滤波完全按用户图片参数：三阶0.5–40Hz带通双向滤波，再做50Hz、Q=30陷波双向滤波，之后重采样到256Hz。
原方案已经是双向带通，本轮唯一新增处理为50Hz陷波。保留原始数据与旧实验，不覆盖。

同一多尺度残差＋RR结构、逐拍标准化、MIT＋INCART训练患者、三个相同种子、训练配置与MIT验证集。审计确认标签、RR、患者划分、中心位置、有效掩码完全一致，只有波形数值改变。

| 方案 | 准确率均值±种子标准差 | macro-F1均值±种子标准差 |
|---|---:|---:|
| 原双向带通 | 72.60% ± 0.76% | 0.4427 ± 0.0113 |
| 双向带通＋50Hz陷波 | 71.91% ± 0.45% | 0.4312 ± 0.0135 |

本轮观察到的平均准确率变化为-0.69个百分点，macro-F1变化为-0.0115。三组macro-F1均未超过原方案，当前没有整体改善证据，七类80%目标仍未达到。V类及伪迹部分指标改善，A/F/L/R召回下降。不能仅凭三种子把变化归因于陷波必然有害，也不能把局部类别改善说成整体达标。

本轮只进行开发验证对照，没有再次使用已查看过的外部测试挑选滤波参数。三种子标准差不是患者总体置信区间；三次训练不能独立证明统计显著性。
双向滤波依赖未来信号，仍为离线方案。没有把MIT-BIH的工频默认认定为50Hz；这里按用户指定参数实验。新增陷波不保证识别提升，也不补充缺失的患者类别。

## 当前任务

每个标签只对应中心的一个标注候选心拍。前一拍和后一拍只提供波形及时间上下文，不参与标签投票。

九类配置保留原始 A、B、F、L、N、R、S、V 和伪迹符号，不合并 A/S 或 V/F，不再把起搏符号当作 N。可用 `--seven` 排除 S/F，保持七类。

标注含义依据 [PhysioNet 官方说明](https://physionet.org/static/lightwave/doc/annotations.html)。伪迹符号表示类似 QRS 的噪声候选，不能称为真实心拍。模型中将其保留为质量类别。

## 单拍数据

1. 从原始 WFDB 波形及逐拍标注重新提取。
2. 以相邻候选标注位置的中点划分周期，窗口长度随心拍改变，不再用十秒窗口。不强行补零凑固定时长。
3. 每个周期插值成 256 点，单拍去均值及标准化。RR 和周期时长另行保存，避免时间归一化后丢掉提前量。
4. 同一中心拍读取前一拍、中心拍、后一拍波形，以及 8 个时间特征。时间特征只使用位置、不读取邻拍类别，标准化参数仅由训练集计算。
5. 缺失、恒定、长度异常及缺少有效相邻波形的目标排除，保存每拍原始位置、边界、标签、记录与集合。

候选位置包含被保留的 QRS 类标注及伪迹候选。因此 RR 是候选间隔，含伪迹时不等同于真实生理 RR。非目标类别的有效拍可以提供波形上下文，其标签不会作为输入。

## 新模型

`src/beat_model.py` 中的 BeatContextNet：

- 共享残差一维卷积分别提取三个周期的形态特征。使用 GroupNorm，减少对批次统计的依赖。
- 保留前、中、后三个位置的特征，中心目标有明确位置。
- 独立 MLP 编码 RR、局部 RR 比值、中心位置和周期时长。
- 融合后只输出中心候选的一个分类结果。

该结构是本项目的新设计，效果以实际记录隔离实验为准，不预设优于旧模型。

## 评估与限制

沿用归档基线的记录集合成员关系，重新生成逐拍样本；不按模型成绩重选记录。归档基线的记录划分此前仅依据标签覆盖修正。仍未完全核实跨记录受试者身份。B 类来源仅一条记录，不能验证其独立泛化能力。

仅训练集按记录最多保留 3000 个 N 拍，全部异常拍保留；验证和测试不作此下采样。类别权重只依据训练计数，验证 macro-F1 选点、早停 8 轮。单个种子的实验不等于稳定提升证据。

专家标注提供理想候选定位和 RR。右侧上下文需要等待后续心拍。这是离线分类实验，不包含自动 QRS 检测误差，不是已完成的实时部署方案。

## 运行

在本目录运行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s src -p test_beats.py -v
.\.venv\Scripts\python.exe src/beat_project.py prepare
.\.venv\Scripts\python.exe src/beat_project.py train
.\.venv\Scripts\python.exe src/beat_project.py train --center-only --tag beat_center_only_seed0
.\.venv\Scripts\python.exe src/compare_runs.py
```

数据和实验拒绝覆盖。原始数据库只读引用相邻的 `项目复现/ECG_ren`。新数据在 `data/`，模型和结果在 `runs/`。

本轮两组完整实验已完成，直接重跑既有 tag 会拒绝覆盖。概览见 `本轮改进与结果.md`，数据校验见 `data/audit.json`，模型详细设计见 `模型与数据设计.md`。

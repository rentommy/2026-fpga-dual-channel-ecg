# 第七轮：新数据与真实时间轴模型

目标：修正RR事件流，在保持原始七类和原MIT患者划分的条件下，检验新结构与新增训练患者是否有帮助。不是十秒窗口分类。

- `run.py prepare`：从MIT、INCART、SVDB原始波形和标注生成256Hz单拍数据；自动检查患者分组、有限值、中心点、补零和整条波形重复。
- `audit.py`：独立逐条核对原始标签、位置和真实心拍前后RR。
- `run.py train`：六组seed0对照，然后重复原结构MIT基线和预选最佳方案的seed1/2；每组最多30轮，7轮无提升停止。
- `evaluate.py`：三种子训练完成后才评估固定候选和基线，生成结果报告及逐患者结果。

第一阶段开发结果不理想后，追加 `normalize_study.py`：比较同模型、同RR和同损失下的逐拍有效点标准化，共四组seed0配置；随后复核逐拍标准化基线与最终候选的seed1/2。这是依据开发结果追加的研究，记录在 `normalization_protocol.json`，不冒称最初就预注册。外部评估在追加研究后才运行。

运行环境使用项目上级的 `.venv/Scripts/python.exe`，所有输出写入本目录，不覆盖旧实验。

结构包括原SE-GRU（20,023参数）、多尺度残差＋RR（195,543参数）、训练集模板初始化卷积＋RR（4,627参数）。新结构不是原论文的精确复现。

类别仍为A、F、L、N、R、V、伪迹。SVDB整库保留为外部数据，S不改为A；因本版输出不包含S，外部七类评估会排除S，并不能代表全部原始心拍分类能力。

INCART固定20名训练、6名验证、6名测试患者。当前训练R仅8拍，主要R来源被分到测试；禁止根据成绩重抽划分。INCART没有L。患者覆盖不足不会因波形总量增加自动消失。

输入是205个点，中心下标77，真实256Hz时间轴。候选范围约中心前0.30秒、后0.50秒，限制在相邻真实心拍中点内，补零附有效掩码；不进行逐拍时间拉伸。候选伪迹仍可以输出质量类别，但不作为真实心拍插入RR序列；与真实心拍同位置的伪迹候选排除并计数。

离线模型使用未来间期、专家标注和零相位滤波，尚不具备在线FPGA部署验证。INCART未进行局部对齐校正；增量数据收益可能受导联/采集差异影响。本轮将多项输入修正作为整体，不把其与旧版的差值冒称为仅修复RR的收益。

审计数据见 `data/manifest.json`、`data/split.json`、`audit.json`。训练状态见 `train.log`，每组保存最佳权重、配置、代码快照、每轮历史及验证预测。测试只在固定选型后运行，旧MIT测试不会重新评估。

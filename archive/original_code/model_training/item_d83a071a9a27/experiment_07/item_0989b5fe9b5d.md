# 第七轮结论：七类80%目标仍未达成

已完成18次训练、10组seed0开发对照、基线/候选多种子复核，以及固定选型后的外部评估。全部保留样本通过原始标签、位置、真实RR与患者隔离审计；重载最佳权重后，MIT验证预测与训练时保存结果完全一致。

最终候选：`multi_z_mixed`，即真实时间轴单拍、逐拍有效点标准化、多尺度残差＋RR、MIT与INCART训练患者联合训练。没有时间拉伸，没有将S改成A或将L/R改成N。

| 方案 | 同一MIT验证集准确率（三种子均值） | macro-F1 |
|---|---:|---:|
| 上轮原基线 | 74.02% | 0.4360 |
| 上轮增强方案 | 70.89% | 0.4410 |
| 本轮最终候选 | 72.60% | 0.4427 |

本轮相对上轮原基线准确率下降约1.42个百分点；macro-F1提高约0.0067。相对上轮增强方案macro-F1仅增加约0.0017。不能据此声称实质性改进，未自动替换部署权重。

## 外部结果怎么理解

- INCART封存测试患者：准确率87.79%，但这里只覆盖A/F/N/R/V，没有L或伪迹；有支持类别macro-F1仅0.5420。它证明部分外部数据上的表现改善，不能证明原七类达标。
- SVDB整库外部评估：七类范围内有效样本准确率79.91%，波动较大；全猜N已有93.03%。该结果不合格，且排除了不在当前输出范围内的S，不能冒称全部心拍评估。
- 外部数据已在本轮最终评估中使用，后续不能再把同一批数据描述为从未查看过的测试集。后续若依据这些结果继续改模型，需要另留最终验证来源。

## 最主要的失败类别

MIT验证三种子平均：A精确率74.16%、召回33.53%；V精确率92.28%、召回81.67%；L召回0.31%、R召回0.87%、F召回11.11%。N召回97.58%，说明总体分数仍主要由常见类别支撑。

新数据没有L；INCART固定划分的训练部分只有8个R，主要R来源在测试患者中。因患者很少，这种不均匀本身就是问题，不能为改善成绩把测试患者搬到训练集。本轮没有证明“只要再多下载普通N/V心拍就可以解决所有类别”。

## 下一步应优先解决的事

1. 若继续要求原七类：先补独立患者的L/R逐拍标注，F也需更多可评估患者和样本；保留患者编号、采样率、导联、心拍位置及原始类型。已有公开两库未补齐这些关键覆盖。
2. 若暂时拿不到这些数据：依据此前允许排除数据不足类别的要求，可另设一个明确缩小类别范围的任务版本；必须另报告保留覆盖率，不能把其较高准确率当作原七类达标。本轮尚未擅自缩小主任务。
3. 暂停继续盲目加深网络。下一次改变应针对导联差异、INCART心拍对齐或新患者数据，做有明确假设的对照；原数据少数患者重复增强不能替代新患者。

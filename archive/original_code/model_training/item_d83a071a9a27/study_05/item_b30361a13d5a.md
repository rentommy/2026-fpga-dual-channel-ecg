## 五项逐一落实

1. **错误审核完成。** 原始标注、重建预处理与实际网络输入一致；保存九张逐记录对照图。A 验证样本集中在 232，R 在 124 与 232 的识别表现悬殊。未因此删除困难记录。详见 waveform_review/审核说明.md。
2. **采样对照完成。** 额外设置普通损失 uniform 对照，将采样作用与损失权重变化分开。

- 去掉损失权重：seed0 macro-F1 0.4275 → 0.4298；A 召回率 21.16% → 18.56%。
- 在普通损失下改变采样：seed0 macro-F1 0.4298 → 0.4205；A 召回率 18.56% → 35.18%。
- 去掉 RR 信息：seed0 macro-F1 0.4275 → 0.3196；A 召回率 21.16% → 13.62%。
- 仅使用 RR 小网络：seed0 macro-F1 0.4275 → 0.3229；A 召回率 21.16% → 1.13%。
- 加入局部形态特征：seed0 macro-F1 0.4275 → 0.4448；A 召回率 21.16% → 34.78%。
- 轻微位置平移：seed0 macro-F1 0.4205 → 0.4369；A 召回率 35.18% → 27.84%。
- 轻微幅值缩放：seed0 macro-F1 0.4205 → 0.4435；A 召回率 35.18% → 36.11%。
- 轻噪声：seed0 macro-F1 0.4205 → 0.4340；A 召回率 35.18% → 37.72%。
- 三项增强组合：seed0 macro-F1 0.4205 → 0.4468；A 召回率 35.18% → 37.92%。

3. **形态/RR 对照完成。** 比较仅形态、仅 RR、二者联合，以及显式局部形态描述融合。显式描述量是原时间轴局部能量、幅值、斜率等，未冒称实现临床 QRS 起止检测。
4. **三种增强及组合完成。** 所有增强只用于训练，分别与相同采样、不增强版本比较。训练标签、验证样本保持一致。
5. **多种子与逐受试者评估完成。** 十个 seed0 方案及基线/所选方案的额外两个种子，保存逐受试者精确率与召回率；未使用旧测试选择方案，也未挑单个最好种子。

## 结论边界

改进是否值得采用，应同时看上表精确率、召回率和多种子结果；总体分数增加不等于所有类别改善。L/R 来源不足，不能用增强或重复抽拍代替补充新受试者。
当前基线按本轮代码重新训练，单种子成绩可能与上一轮有小幅差异；实际对照采用本轮同设置的基线与方案，不将跨轮差值当成单因素收益。
尚未完成新的独立外部测试、自动心拍检测或硬件部署验证。本轮不会替换部署权重。

**所选方案的三种子平均 macro-F1 比基线增加 0.0050；这是当前开发验证上的增益，仍需独立验证。**

**重复实验未显示一致收益，不能确认稳定提升。所选方案不自动替换基线。**

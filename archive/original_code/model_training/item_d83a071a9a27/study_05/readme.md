# 五项改进的受控实验

本轮输出仍为 A/F/L/N/R/V/|，B/S 暂时排除；| 是质量类别。第三轮测试已被查看，整轮只使用训练/开发验证，不再将旧测试用来选方案。

1. `inspect_errors.py`：使用上一轮 SE＋GRU 的验证预测，为 A/L/R 每条验证记录画原始波形、实际处理结果和网络输入。固定选首个正确/错误例及训练参考，重建原始标注和滤波输入，输出逐记录错误表。
2. `uniform` 与 `balanced`：普通损失下对照均匀抽拍与分层抽拍。分层概率按类别拍数平方根分配，再在该类别的受试者间平均分配，受试者内部均匀抽拍，有放回，总抽样数保持不变。它减轻正常类和长记录主导，不创造新的受试者。
3. `morph_only`、`rr_only`、`feature_fusion`：检查形态、RR 信息和额外真实时间轴局部形态描述。局部能量宽度不是经核验的 QRS 起止时长。固定特征区间为中心前后约 150ms，标准化仅拟合训练集。
4. 在 `balanced` 上分别增加 ±3 个归一化采样点平移、0.9–1.1 幅值缩放、标准差 0.02 的轻噪声，以及预先固定的三项组合。没有翻转、时轴拉伸、循环移位或引入相邻心拍；标签不变，RR 不变。增强只用于训练，不与显式形态融合同时启用。
5. 十组都先训练 seed0，按开发验证 macro-F1 选择一组，然后对该组和 baseline 补 seed1/2。所有组保存逐受试者类别分数；不挑最好种子充当最终性能。

每组 25 轮上限、6 轮早停，batch=256、AdamW lr=0.001、weight_decay=0.01，与上一轮相同。baseline 保留上一轮加权 SE＋GRU；uniform 去掉权重，以便把采样效应和损失权重效应分开。

```
../.venv/Scripts/python.exe -m unittest -v test_study.py
../.venv/Scripts/python.exe inspect_errors.py
../.venv/Scripts/python.exe -u study.py run
```

运行拒绝覆盖已冻结的协议/运行目录。`protocol.json` 在训练前写入；各运行保存源码快照、哈希、配置、采样审计、权重、训练曲线、逐拍验证预测与逐受试者指标。

本轮是开发阶段对照。三个种子的波动不能代替独立受试者置信区间；多次在同一验证集选方案仍可能过拟合验证集。L/R 来源覆盖不足、专家定位和离线滤波条件也没有因为本轮训练而消失。

## 已完成结果

14 次训练全部结束，所有权重重新加载后的完整验证预测均与保存结果一致，检查见 audit.json。汇总见 [五项工作总结](五项工作总结.md)、[完整对照表](结果报告.md) 和 [三种子对照图](三种子对照.png)。

当前不推荐用采样增强组合替换基线：三种子 macro-F1 均值仅增加约 0.0050，标准差由 0.0065 增至 0.0395，A 的精确率和召回率均值均下降。L 平均召回率上升主要由一次种子贡献，尚不稳定。保留这些实验用于后续分析。

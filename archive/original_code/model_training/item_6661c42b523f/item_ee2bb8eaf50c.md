## 用途和缺口

- INCART可补充A、V、F的患者多样性；R虽有3,173个位置有效标注，却只有2名患者。F来自14名患者，但总量219仍少。
- SVDB提供12,188个S，覆盖73条记录。S不能直接改为A，应保留原始标签，可作为独立输出或辅助任务。
- 两库均没有L。请优先补充来自更多独立患者的L逐拍数据，保留患者ID、导联、采样率、原始波形、每拍位置与类型。整条记录的LBBB诊断不能直接当作每拍L标签。
- 伪迹符号是质量事件而非真实心拍；节律/质量标记不自动并入N，完整符号统计见JSON。
- 训练前先冻结患者划分，留出不参与预训练、调参或域适应的外部患者。当前仅下载与审计，尚未用新数据训练。

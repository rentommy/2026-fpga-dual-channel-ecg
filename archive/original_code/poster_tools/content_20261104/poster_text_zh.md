## 项目简介 / INTRODUCTION

本项目以 PYNQ-Z2（AMD XC7Z020）与自主设计的 ADS1292 采集板为基础，构建双输入通道心电监测原型。系统通过隔离 SPI 获取 24 位、500 Hz 采样数据，采用 PS–PL 协同架构，实现双路径数字滤波、心率估算、逐拍辅助识别和 HDMI 波形显示。每个输入同时产生低延迟实时路径与延迟补偿保真路径，用户可通过 SW0 在单路与上下双路径显示之间切换，直观观察同一输入在不同滤波路径中的形态与时间差。

## 典型应用 / Typical application case

适用于嵌入式生物电信号处理教学、数字滤波对比实验、心电算法硬件部署与人机交互展示。在一个系统中演示从自主采集硬件、数据预处理到 FPGA 卷积计算和逐拍标签显示的完整流程。

## 关键技术问题 / Key technical issues addressed

1. 采集与接口：在隔离连接条件下完成 ADS1292 寄存器配置、DRDY 驱动采样读取、帧校验与 FIFO 缓冲。
2. 延迟与波形形态：以同一采样序列生成两条不同延迟的滤波结果，避免只展示单一路径而掩盖设计取舍。
3. 模型协同部署：保持 FP32 权重与训练输入定义，划分 FPGA 卷积和 ARM 归一化、RR 特征及分类任务。
4. 实时显示：使滚动波形不等待模型计算完成，将识别结果延后回填至对应心拍，并通过双缓冲降低换帧错位。
5. 信号可信度：对平直、削顶和强噪声等情况进行质量门控，输入故障时清除过期心率与分类提示。

## 系统架构 / System Architecture

采集板完成模拟心电的采样，隔离接口连接 PYNQ-Z2。PL 侧 SPI/FIFO 接收数据，PS 将原始样点组织为 DDR 缓冲。数据随后进入两条独立用途的处理流程：显示流程调用 PL 双路径滤波核，由 PS 整理波形并写入视频缓存；识别流程在 ARM 上进行训练匹配的预处理、R 峰定位与心拍切分，再通过 FPGA 卷积协处理器完成网络卷积计算。ARM 汇总心率、质量与分类信息，与波形一起送入 PL 视频模块，最终由 HDMI OUT 输出。

### 模块一：自主采集板与隔离接口

ADS1292 提供两个 24 位采样通道，配置采样率为 500 Hz。采集板使用电池供电，经数字隔离接口与开发板通信。PL SPI 主机控制 CS、SCLK、DIN、START 和 PWDN/RESET，并读取 DOUT 与 DRDY。输入帧通过状态字检查后进入 FIFO，PS 负责读取与组织。CN4 对应通道1，CN2 对应通道2；目前两个通道分别完成了电极采集测试。

### 模块二：双路径数字滤波核

滤波核共享温和高通与 320 点滑动平均基线估计，为每个通道配置不同的延迟抽头。两条路径分别经过 50 Hz 陷波与 31 抽头 FIR 低通，形成实时和保真输出。当前滤波核使用单 DSP 时分复用计算，并保存各逻辑通道状态；两条输出持续提供给系统，不应描述为两套完全独立、零调度开销的并行流水线。八逻辑通道的验证不等于八路物理 ADC。

### 模块三：FPGA 卷积与 ARM 识别

选定模型包含 195,608 个参数，全部 12 个 Conv1d 层由共享 FP32 卷积加速器执行。ARM 负责层间 GroupNorm、激活、池化、门控、RR 分支及全连接分类。模型从原始采样独立进行 0.5–40 Hz 带通、50 Hz 陷波和 256 Hz 重采样，形成 205 点波形及有效掩码，并输入 8 维标准化 RR 特征。模型流程不直接使用 HDMI 保真显示支路作为训练匹配输入。

### 模块四：交互显示与状态管理

HDMI 输出滚动波形、心率、信号质量与延时逐拍标签。SW0 控制单路/上下双路径显示，上方为实时路径，下方为保真路径；BTN0/BTN1 同时切换两栏对应的采集通道，BTN2 切换单路滤波模式，BTN3 冻结/恢复波形与标签。两条路径共用当前通道的显示增益和时间窗口，保留原始时间差；状态栏在冻结时仍更新。

## 关键创新点 / CREATIVE DESIGN

**1. 同源双延迟输出与可视化比较。** 共享基线估计与历史状态，通过不同抽头产生两条滤波路径，并由 SW0 在单路径和上下双路径间切换。既展示低延迟观察，也展示延迟补偿后的形态差异，不人为平移两条波形来掩盖差别。

**2. 面向当前采样负载的资源复用。** 滤波核利用 100 MHz 时钟与 500 Hz 采样之间的时间预算，以单 DSP 时分复用完成计算。卷积层共用 FP32 加速器，在保持既有权重的条件下完成实际 FPGA 部署，避免把资源堆叠本身当作性能提升。

**3. 波形与识别解耦的延后标注。** 独立推理进程和有界任务队列使显示不等待分类。识别结果按源样点位置和路径延迟映射回对应心拍，波形、移动标签与状态缓存同步换帧。

**4. 可核查的部署与故障处理。** 通过黄金参考、RTL 仿真、实际时序报告和板端分类对照验证实现；通过质量门控、ABI 检查与故障清空机制减少错误输入和过期结果造成的误导。

## 测试结果 / RESULT

已完成两个输入通道的分别采集、ADS1292 内部测试信号、滤波参考对照、SPI/FIFO/按键/视频/SW0 仿真及板端模型部署。用户已确认中文显示、按键、标签平滑和 SW0 分屏正常。两段自采记录共 49 个可用心拍的板端分类与 PyTorch 参考结果全部一致，最大 logit 绝对误差约为 2.384×10⁻⁶。该结果是部署数值一致性，不是临床分类准确率。

固定供电后的一次约30秒复查中，采样计数持续增长，丢帧和坏帧计数均为0，质量状态恢复良好，模型进程正常。长期稳定性和最新版断电自启动仍需进一步验收。

# 采集板、HDMI 波形与按键使用

本版把已有 HLS 滤波器、PL SPI 主机、采集 FIFO、波形缓存与视频输出放进同一个 overlay。旧 `board/overlay/` 与修复版工程保留；新产物位于 `board/scope/`。

## 需要买 Pmod A 连接器吗

PYNQ-Z2 本身已经焊有标为 **PMODA** 的黑色 12 孔插座，标准针距2.54 mm。Pmod A 不是需要购买的功能模块。

用户目前尚未设计隔离器主机侧：

- 临时连线：主机侧若做普通排针，用**公对母杜邦线**，公端接 PYNQ 的 PMODA 插座，母端接主机侧排针。七根信号加一根主机地，共八根；隔离器主机侧供电另外接。
- 正式 PCB：可以做标准 **2×6、2.54 mm Pmod 公头**，直接插接，或使用保持针号对应的延长线。画板前核对实物插接面、1脚标识和 PCB 封装，不能把插接面与焊接面镜像。
- 不需要购买 Pmod ADC 模块，也不需要改用板上的40针扩展接口。

## 固定接线

以下均指**数字隔离器的 PYNQ／主机侧**，不是直接接到 ADC／人体侧。

| 主机侧信号 | PMODA 物理针号 | FPGA 球号 | 隔离方向 |
|---|---:|---|---|
| CS | 1 | Y18 | PYNQ → ADC |
| DIN / MOSI | 2 | Y19 | PYNQ → ADC |
| DOUT / MISO | 3 | Y16 | ADC → PYNQ |
| SCLK | 4 | Y17 | PYNQ → ADC |
| DRDY | 7 | U18 | ADC → PYNQ |
| START | 8 | U19 | PYNQ → ADC |
| PWDN/RESET | 9 | W18 | PYNQ → ADC |
| 主机地 GND1 | 5 或11 | — | 接隔离器主机侧地 |

10脚空置。6或12脚是 **PYNQ 侧3.3 V**，可供满足电流预算的隔离器主机侧 VDD1；不要接到采集侧电池供电或采集侧地。隔离器需 **五路去、两路回**，DRDY、START、RESET 也不能跨隔离屏障直连。采集侧 VDD2/GND2 保持独立。已有 STM32 的输出必须从这些总线上断开，避免双主机驱动。

设计时按隔离器具体型号检查方向、上电默认输出及传播延时。ADC侧 CS、START、RESET 的上电状态也要由电路保证；PL 未配置前的高阻态不能充当复位时序。现有采集板 CLKSEL／CLK 接法应保留；SPI SCLK 不是 ADC 主时钟。

针号依据 [TUL PYNQ-Z2 Reference Manual v1.1](https://dpoauwgwqsy2x.cloudfront.net/Download/PYNQ_Z2_User_Manual_v1.1.pdf) 与本地厂商 XML。ADC时序依据 [TI ADS129x 数据手册](https://www.ti.com/lit/ds/symlink/ads1292r.pdf)。新主机采用 Mode1、MSB优先，100MHz下SCLK约561.798kHz；CS前后保留保护间隔，ADC主时钟仍由采集板提供。

## 显示器与按钮

用普通 HDMI 线连接 **PYNQ 的 HDMI OUT → 显示器 HDMI 输入**，选择该输入源。本版固定为 **640×480、60Hz**，显示器需支持这个输入模式。输出是通过 HDMI 接口传输的 DVI 兼容 RGB 视频，没有音频、HDCP 或 EDID 自动选模；不要求买带屏 Pmod 模块。用户目前没有连接显示器，实物画面还需后续验收。

| 开发板按键 | 功能 |
|---|---|
| BTN0 | 显示 CH1 |
| BTN1 | 显示 CH2 |
| BTN2 | 切换 DIAG 诊断通路／FAST 快通路 |
| BTN3 | HOLD 冻结显示／LIVE 继续显示 |

按键有约20ms消抖，按住不会反复切换。显示冻结时采集、滤波仍继续；恢复后显示最新窗口。横轴约4秒，纵轴共用自动增益（AUTO），不作为固定毫伏刻度。图像由PL以60Hz扫描；2026-11-03脚本将PS波形更新目标从约10Hz提高到默认25Hz，可用 `--display-fps 25` 调节（1～60），实际更新率和绘图耗时在退出summary中记录。该频率不是采集到显示的实测延迟，也不是屏幕实际呈现的完整帧率。

2026-11-03：修复绘图时相邻列未连接的问题。每列保留采样点最小/最大值，并纳入上一列最后一个采样点，避免陡峭QRS出现断线。修改位于 `run_scope.py`，不需要重新生成比特流。`HOLD` 表示冻结，按BTN3恢复 `LIVE`。旧的20261023压缩包仍是历史版本，重新解压后需重新应用此次脚本修复。

## 板上运行

将发布包解压到一个项目目录，保持 `board/` 与 `data/` 的相对结构。bit 和 hwh 必须同名且同目录。

演示模式不发送 ADC 命令，使用明确标注的合成数据：

```python
%run board/run_scope.py --source demo
```

短时检查可加 `--duration 8`。程序退出会停止自动采集并冻结最后的显示；重启开发板后需重新运行。没有安装自动启动服务。

隔离板、采集板和时钟都接好后，先用 ADC 内部测试信号：

```python
%run board/run_scope.py --source adc-test
```

最后才用真实外部输入：

```python
%run board/run_scope.py --source adc
```

真实采集会检查ID（0x53／0x73）、配置寄存器回读、DRDY超时、帧头和溢出计数；发生错误会报出并停止，不把丢帧隐藏成连续波形。新配置启用CH1和CH2、增益6、500SPS；旧STM32代码仅启用了CH2，不能直接复制其单列数据当作双通道。

## 架构与接口

- `ecg_filter_0` 仍位于 `0x40000000`，DDR布局及驱动寄存器保持兼容。
- `ecg_io` 位于 `0x40010000`。1024帧FIFO，500SPS时约2秒容量。每次 DRDY 读取24位状态及两路24位数据；PS读三字并在最后一字后弹出FIFO。
- PS批量送两路输入到既有八通道滤波器，剩余逻辑通道置零；状态跨块保持，首543点只丢弃一次。
- SPI和控制为100MHz时钟；视频像素25.2MHz，串行126MHz。Digilent官方BSD-3-Clause `rgb2dvi` 核完成TMDS编码与串行化，其RGB字节排列已适配。
- 显示缓存包含前后台两份，每份均有四个640列min/max波形bank，按通道和通路选择。PS完整写入后台后提交切换请求，PL在垂直消隐起点（hx=0、vy=480）切换，并将当前缓存编号同步返回PS；等待切换完成时禁止继续写缓存。通道、通路和标签也在帧边界切换。

### ecg_io 寄存器

| 偏移 | 含义 |
|---:|---|
| 0x00 | 控制：bit0 RESET_N，bit1 START，bit2自动采集，写bit3清FIFO与计数；默认1 |
| 0x04 | bit0 SPI忙，bit1命令完成，bit2溢出，bit3无效帧；bit26:16 FIFO数量 |
| 0x08 | 写1～16启动相应字节数的手动SPI交易，仅在自动采集关闭且空闲时允许 |
| 0x0C | SCLK半周期拍数，默认89 |
| 0x10 | UI状态：bit0通道，bit1通路，bit2冻结；bit11:8原始同步按键 |
| 0x14 | 软件选择通道／通路／冻结，低三位与UI状态相同 |
| 0x18 | 显示标签：0采集信号、1演示波形、2无数据/错误、3内部测试信号（中文版本） |
| 0x1C | 读：bit0当前前台缓存，bit1请求缓存，bit2切换待确认；写bit0提交目标缓存（仅无待确认请求时） |
| 0x20/24/28 | FIFO帧头／CH1／CH2；24/28为符号扩展32位，读28后弹出 |
| 0x2C/30/34 | 完成帧数／溢出数／无效帧数 |
| 0x38 | HDMI HPD，不能单独当作画面正常的证据 |
| 0x3C | ABI标识0x45434732（双缓冲版本，需配套新版run_scope.py） |
| 0x100～10C | SPI发送缓存，字节0放在低8位 |
| 0x200～20C | 最近手动SPI响应，字节序同上 |
| 0x4000～67FC | 只写后台波形窗口，2560个32位字，低20位为y_max与y_min；全部写完后提交0x1C |

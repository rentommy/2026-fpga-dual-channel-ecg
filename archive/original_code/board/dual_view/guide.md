# SW0 双路径 HDMI 显示

SW0=0：单路显示，启动默认低延迟实时路径；BTN2 仍可在单路下切换路径。

SW0=1：当前选中采集通道的两条滤波路径同时显示。上栏为实时路径，下栏为保真路径。BTN0/BTN1 同时切换上下两栏的采集通道，BTN3 同时冻结/恢复上下两栏。双路模式的路径固定，不由 BTN2 改变；拨回单路后恢复单路所选路径。

两栏共用 4 秒时间窗口与同一自动增益，垂直幅度压缩为单路的一半。保留滤波路径的原始时间差，没有人为平移对齐。标注的 30 ms、348 ms 是既有滤波核脉冲峰值偏移，不能当作 HDMI、采集和识别的端到端延迟。

两路来自同一输入的并行滤波结果，不表示两个电极输入通道。逐拍模型标签保持各自路径的既有时间补偿，并分别出现在对应栏顶部。心率与质量状态栏仍由当前选中采集通道驱动。

固件接口 ECG6（0x45434736），模块名 ecg_io_dual，新增只读寄存器 0x40 bit0 返回经过同步及消抖后的 SW0。新软件与新 bit/hwh 配套使用。

SW0 对应 PYNQ-Z2 M20，依据项目 board_files/pynq-z2/A.0/part0_pins.xml。切换状态在垂直消隐时锁存，不改变正在扫描的画面布局。

构建：board/build_dual_view.tcl。验证：board/test_dual.ps1，覆盖双路径 RAM 选择、上下坐标映射、帧边界切换、恢复单路、SW0 消抖/寄存器以及原有视频/SPI/FIFO/按键行为。

原 ecg_monitor_20261104 安装目录保留；新版本使用独立 ecg_dual_view_20261104 目录。安装前备份的服务文件为 ecg-scope.service.before-dual。

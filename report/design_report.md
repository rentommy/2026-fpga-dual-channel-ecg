# 当前设计报告

## 背景与目标

作品面向嵌入式心电采集与可视化教学，展示同一输入的两条滤波路径及PS/PL协同推理。核心价值包括自主采集板与隔离接口集成、可配置双延迟滤波、FPGA卷积部署与不阻塞波形的延时识别显示。

## 系统结构与划分

ADS1292经隔离SPI进入PL的DRDY驱动采集/FIFO。ARM读取原始数据并提交滤波核，PL并行形成实时/保真两条输出。视频模块从双缓冲波形、逐拍标签和状态缓存生成HDMI，帧边界同时换帧。

PL计算重复的滤波与12层FP32卷积；ARM负责R峰、RR、GroupNorm/门控/全连接、质量门控、心率和服务控制。卷积使用独立推理进程和有界队列，显示不等待分类。当前QRS/心率位于ARM，原早期简介中“PL完成QRS/心率”的目标尚未实现，也不再作为当前功能声称。

SW0选择单路/上下双路径，BTN0/1选输入、BTN2选单路路径、BTN3冻结。两栏共用当前输入的增益，另一未使用输入不会压缩当前波形。30/348ms为滤波峰值偏移，识别因依赖下一RR而约延后2–3秒。

## 优化与证据

| 优化 | 原行为 | 当前行为/证据 |
|---|---|---|
| 滤波资源 | 早期综合资源超限 | 单DSP调度滤波核，八逻辑通道；仅两个物理ADC通道 |
| 标签定位 | 16像素对齐导致约10Hz跳位 | 像素定位，与波形同帧提交，用户确认平滑 |
| 显示路径 | 单次仅显示一个路径 | SW0上下同时展示，用户确认分屏 |
| 缓存所有权 | 异常清理曾出现SEGV | 显式普通NumPy复制，49拍回放保持一致；不声称所有退出故障均已穷尽 |
| 模型部署 | 首版143.61ms/拍、前三拍约1.25倍 | 后续约120ms/拍、前三拍约1.51倍；仅特定单线程NumPy对照 |
| 显示增益 | 两输入共同增益 | 当前输入的两路径共同增益，极端未使用通道干扰用例通过 |

最新显示固件WNS+0.016ns、WHS+0.002ns，LUT15735、FF20490、BRAM60、DSP57，报告在build/reports。49拍硬件与PyTorch一致、最大logit误差2.384e-6，证据在report/evidence。用户确认电源反复断开是现场断流的重要原因，固定后约30秒复查计数增长、无丢帧/坏帧、质量GOOD；长期稳定性未验证。

## 协作、技能与复现

大模型协作见llm_log，包括失败、用户纠正与随后验证。技能包提炼了时序证据门控、Overlay ABI检查、DMA缓存所有权和电源/通信分层排查。工具不绑定心电，适用范围和失效条件见skill/README.md。根README及docs/reproduce.md提供复现步骤，新增干净构建路径已完成HLS至bit重建，报告见full_clean_build_2026-11-04.md；新bit上板待验收。

## 验证边界

模型不是医疗诊断。自采数据无专家标签，非N输出不能作为健康结论。两个输入分别有电极验证，不代表同步双导联实验。八逻辑通道仿真不代表八路ADC实测。资源上限推算不等于已实现通道数。没有测量整机功耗、端到端采集显示延迟和全覆盖临床分类性能，不能补造这些数字。

## 1. 先把不可能的部分证明掉

动手之前先问：有没有可能延迟短、形态准、漂移又去得干净？

**没有，这是定理不是调参问题。** 因果最小相位 LTI 系统的 `ln|H(ω)|` 与
`arg H(ω)` 是希尔伯特变换对（Bode 增益—相位关系）。也就是说，
**高通的幅度特性一旦定下来，带内相位就被锁死了**，没有任何自由度。

唯一还能帮忙的全通环节是**纯延迟**，而它需要的延迟量按 `1/fc` 增长 ——
拐点越低（漂移去得越干净），需要的延迟越长。

所以"低延迟 + 保形态 + 强去漂移"三者不可兼得。
**阶段一那条 0 乘法的移位级联链，真实有效高通拐点是 0.98 Hz。**
IEC 60601-2-25（诊断心电）要求 0.05 Hz，正是因为更高的拐点会扭曲 ST 段；
60601-2-27（监护）允许 0.5 Hz，但标准里明确写了不适用于 ST 分析。
**也就是说阶段一是拿监护级的滤波器做诊断级的测量。**

> 标准条款号在提交前需要逐条核对原文，本章全部外部引用同此要求。

## 2. 唯一的出路是延迟 —— 一次消融实验

阶段一之后试过一整条非线性/时变的路线（双链路渐变合并、QRS 期间门控基线更新、
斜率外推、变时间常数、等电位点锚定等十余种，全部归档在 `old/nonlinear_gated/`）。
动机是：既然 LTI 有定理挡着，那就跳出 LTI。

其中"方案 F"看着最有希望：一阶 IIR 估基线 + 一个随偏差自适应的权重 `w` +
信号通路延迟 D 对齐。做了一次 2×2 消融（k_g=7, k_lp=7, D=116）：

| 去掉什么 | 结果 |
|---|---|
| 去掉自适应权重 `w`（令 w≡1） | 几乎没变：0.051 → 0.041 |
| 去掉延迟补偿 D（令 D=0） | **塌回阶段一定稿数值完全相同的值** |

两行表说明一件事：**这一路所有收益的唯一有效成分是延迟对齐，
非线性那一层是死重。** 而且 `yg - lp` 在数学上本来就是第二级高通，
这就是去掉 D 之后会和阶段一定稿**逐位相同**的原因。

教训记在这里：延迟从一开始就被我默默排除在搜索空间之外了，
于是绕了一整天去找"不用延迟的办法"。
**一个"某类方法必然做不到"的断言，代价远大于一个错误的参数。**

顺带也否证掉了两类"用预测换延迟"的想法：

- 喂真实未来基线的**先知实验**在 30 ms 延迟下能到 0.9896 / 96%，说明架构没问题；
  但真实预测器误差按 `m^1.3` 增长（m=40 点误差 6.4%，m=200 点 32.7%）。
- 3 抽头维纳滤波器对它的抽头集是 MMSE 最优的，所以
  **Savitzky-Golay 边缘外推不可能更好**，线性高斯卡尔曼就是递归维纳，同一个界。
- 在线 LMS 在这里根本不收敛：权重范数 30 秒内 1.019→0.829→2.180→2.617→2.092；
  电极脱落时输出冲到 1486 mV，是纯延迟 LTI（270 mV）的 5.5 倍。

## 3. 换零件：为什么是矩形窗

既然有效成分是延迟对齐，问题就变成：**哪个基线估计器最容易被一个固定延迟对齐？**

### 3.1 判别量是群延迟平坦度，不是群延迟大小

一个固定的延迟量 D 只能对齐一个频率。基线估计器的群延迟在带内变化越小，
一个 D 能同时对齐的频带就越宽：

| 基线估计器 | 0.05～1 Hz 的群延迟变化 |
|---|---|
| 一阶 IIR（移位 k=8） | 249 点 → 22 点，**变 11.25 倍** |
| 半高斯核 σ=180 | 2.83 倍 |
| **矩形窗 L=400** | **1.00 倍** |

矩形窗的群延迟恒为 `(L-1)/2`，与频率无关。**一个 D 把所有频率一次对齐。**
这就是换矩形窗的全部理由 —— 不是因为它滤得更好，而是因为它好对齐。

### 3.2 `z^-D − B(z)` 是线性相位 FIR 高通

把延迟后的信号减去矩形窗均值，整体就是一个线性相位 FIR 高通。
这一步不是我们发明的；**我们的贡献是认出它该用在这里，并且用滑动和实现它**：

```
box_sum += yg[n] − yg[n−L]        每点一次加、一次减
lp = box_sum × (2^20 / L) >> 20   一次乘法完成归一化
```

直接做 320 抽头 FIR 要 320 次乘法，滑动和只要 **1 次**。
全链每通道每采样点 22 次乘法（1 归一化 + 5 陷波 + 16 折叠 FIR），
与阶段一的 21 次相比只多 1 次 —— 却换来了 §0 那张表的收益。

### 3.3 L 的下限由心拍长度决定

窗比一拍短，窗里就装着 QRS 和 T 波本身，基线估计被自己的心跳顶高，
减完造成 **ST 段系统性读低**：

| L | 窗长 | 占一个 RR | 基频泄漏进基线的比例 | ST60 偏差（两段数据） |
|---|---|---|---|---|
| 256 | 512 ms | 0.62 | 0.47 | −0.068 / −0.065 mV |
| **320** | **640 ms** | **0.78** | **0.26** | **−0.028 / −0.036 mV** |
| 512 | 1024 ms | 1.24 | 0.18 | −0.001 / −0.030 mV |

实测 RR 间期 824 / 878 ms（73 BPM，心搏基频 1.217 Hz）。
**0.1 mV 的 ST 压低就是临床判读阈值**，
所以 L=256 的 −0.068 mV 会直接造成假阳性 —— 这不是精度问题，是会误诊的量级。

L 没取 512 是因为延迟按 `(L-1)/2` 增长，512 要 511 ms，
而收益（ST 偏差 −0.028 → −0.001 mV）已经在噪声量级里。
L=320 的 −0.028 mV 是临床阈值的 28%，接受。

> **本节的一处修正（2026-10-20）。** 原先这里写着"矩形窗的频谱零点在 `fs/L`，
> L ≈ 一个 RR 时心搏基频正好落在零点上，被整个零掉"。**这句对 L=320 是错的。**
> 零点在 `fs/320` = 1.5625 Hz，而心搏基频是 1.217 Hz，该处增益 **0.262**
> —— 泄漏了 26%，远不是零掉。
>
> 要让零点正好压住基频，L 得取 `fs/f_心搏` = 500/1.217 ≈ **412**，
> 该处增益降到 0.0025。这个 L 确实存在、而且理论上更漂亮，但**没有采用**：
> 它随心率变（60 BPM 要 500，100 BPM 要 300），而 `DC_BOX_L` 是编译期常量；
> 做成跟随心率的自适应窗长就不再是 LTI，回到了 §2 已经否证掉的那条路。
>
> L=320 处那 26% 的泄漏，表现在 ST 偏差上就是 −0.028 mV。
> 也就是说：这一行的收益本来就是靠**窗够长**挣的，不是靠零点对齐挣的。

### 3.4 L=320 是偶数，严格线性相位要奇数

严格线性相位要求 `D=(L-1)/2` 是整数，也就是 **L 必须为奇数**。
L=320 留下了一个 `1/320` 抽头的不对称。

实测这个不对称的影响是 **0.0006 mV**，在噪声以下，所以定稿没改。
> 记一笔：这条假设第一次验证时用了一个坏掉的对称性度量 ——
> 它只比较平坦部分，从不检查尖峰是否居中，于是对所有 L 都报 0。
> 理论是对的，效果可以忽略，两件事都要说。

## 4. 验收指标的方法论修正 —— 推翻阶段一 §1

阶段一 §1 把验收指标定成"按 R 波对齐的平均心拍模板相关"。**这个指标有两个盲区：**

| 盲区 | 为什么 |
|---|---|
| 对基线漂移**盲** | 逐拍平均把漂移抵消掉了 |
| 对幅度**盲** | 模板做 L2 归一化，幅度被抵消掉了 |

而漂移和 ST 幅度恰恰是这一章在乎的两样东西。
这个坑在定稿前**踩了四次** —— 最后一次是给一个残留漂移 0.815 mV 的方案
标了星号，就因为它的模板相关是 0.9974。

改用的指标：**逐拍临床测量**。每一拍以自己的 PQ 段为零点，
量 ST60 和 T 峰，与零相位参考逐拍配对求误差。换指标之后
**候选方案的排序直接反过来了** —— 这不是精度提升，是结论变了。

两条必须一起说清的保留：

- **逐拍 PQ 参考能抵掉约 90% 的漂移**（拍内漂移 RMS 0.085/0.073 mV，
  对比全程 0.815 mV），但 0.08 mV 仍是 0.13 mV 级 ST 信号的 60%，
  **所以去漂移这一步省不掉**。
- **参考是相位真值，不是幅度真值。** `filtfilt` 自己那级 0.5 Hz 高通
  会衰减 T 波，所以"T 波占参考的百分比"可以超过 100%（实测 104%）。
  拿它当幅度金标准会得到荒谬结论。

还有一个方法论坑：**启动瞬态会污染全程最大值/峰峰值统计。**
曾经那个 3.060 mV 的"最坏漂移"出现在 t=0.5 s，是滤波器自己还没稳。
现在所有峰峰值统计都掐掉首尾 2 秒。这个指标前后坏过两次。

## 6. 双延迟通路 —— 新增的架构维度

§0 那笔交易（漂移降 4.8 倍，延迟从 32 ms 涨到 348 ms）**不需要全局做决定**。

| 通路 | 延迟 | 服务于 |
|---|---|---|
| path 1 低延迟 | **30 ms** | 实时波形显示、报警，以及肌电一类闭环场景 |
| path 0 诊断 | **348 ms** | ST 段测量、波形存档、模型推理 |

两条通路**共享前级**（温和高通 + 矩形窗滑动和），只在延迟抽头之后分开。
延迟量 `DC_DELAY_CFG[通道][通路]` 是编译期参数，逐通道可改。

一个容易想错的地方，值得写进报告：**这两条不是"同一个滤波器平移"。**
path 0 算 `yg[n−159] − lp[n]`，path 1 算 `yg[n] − lp[n]` ——
它们减的是**同一时刻**的基线估计，所以是两个不同的滤波器，
把 path 0 延迟 159 点也不会等于 path 1（实测差 11460 码）。
> 这一条是顶层测试平台的第三项检查抓出来的 —— 抓的是我的错误模型，不是设计缺陷。
> 现在那项检查改成了验证冲激响应峰值的位置。

低延迟通路的诚实评价：在 ST/T 逐拍误差上它比阶段一定稿好 1.3～1.7 倍，
但在**残留漂移上更差**（0.276 vs 0.150 mV）。它不是"全面更好的旧定稿"，
是一个为低延迟场景做了不同取舍的通路。肌电假肢控制文献给的可接受延迟约
100～125 ms，30 ms 留足了余量。

## 7. 多通道扩展 —— 瓶颈在存储不在运算

500 SPS、100 MHz，**每个采样周期有 20 万个时钟**（阶段一 §2.0 的结论）。
8 通道 × 2 通路 × 22 次乘法 = **344 次乘法**，占一个 DSP48E1 的 **0.172%**。
运算量根本不是约束。

真正的约束是 BRAM。这里有一个省一半存储的做法：
**延迟线直接复用矩形窗的历史 RAM。** 因为 `DC_DELAY_MAX`(192) < `DC_BOX_L`(320)，
需要的延迟抽头本来就在窗的历史里；BRAM 是双端口的，
一个端口读"离开窗口的那个样本"，另一个端口读延迟抽头。

每通道每通路省 4608 bit。通道上限从约 260 提到 **约 520（双通路）/ 570（单通路）**。
> 这个数第一版算错了 2 倍，就是因为漏掉了复用这件事。

## 8. 定点实现上踩到的坑

| 坑 | 现象 | 处理 |
|---|---|---|
| 移位 IIR 的死区 | `acc += (x−acc)>>8` 用整数存储时，`\|x−acc\| < 256` 就完全停住（±0.0123 mV 的死区） | 加 `DC_ACC_FRAC=8` 位小数 |
| 右移的算术/逻辑之别 | 心电是**带负均值**的有符号量（实测 −3.942 mV），逻辑右移会把负数变成巨大正数 | 测试平台里加运行期断言；`ap_int<N>` 本身是算术移位 |
| 黄金参考实现了硬件做不到的算法 | Python 的 `boxcar_lp` 在预热期按**实际点数**求平均，而硬件只有一个固定的 `1/L` 乘数 | **改 Python 不改硬件**，并定义 `ECG_WARMUP=543` 为无效输出区 |
| 反馈环里的舍入 | 反馈环内做舍入可能产生极限环 | 陷波/FIR/矩形窗用舍入移位，`hp_acc` 反馈环用截断 |

第三条是冲激测试抓出来的，偏差 60780 码。
**黄金参考必须只实现硬件做得到的算法** —— 否则它不是参考，是另一个待调试对象。

# 实时心率、信号质量与预警集成

2026-11-04。用户要求补齐心率显示、信号质量/预警及真实电极整机连续验证；断电启动由用户自行测试。电极连接CN2，启动通道2。

## 已实现

- ARM从R峰间期计算心率，以最近最多5个有效RR的中位数为基础平滑显示；不把这部分描述为PL侧QRS或心率硬件。
- 新增中文状态栏，显示心率、信号质量及观察/预警状态。冻结仅固定波形与逐拍标签，心率、质量及故障提示继续更新。
- 检查平直、削顶、强工频、高频噪声和大幅低频扰动；无有效RR、质量差、分析过期或故障时显示“--”，不沿用旧心率。
- 分类需要通过当前窗口及心拍局部窗口的质量门控；不合格心拍被拒绝并计数。质量恢复后再恢复显示与预警累计。
- 输入断流或初始化失败时清空分类、清除心率、显示“采集故障”，并保存`acquisition_fault.json`。服务可按失败重启。
- 滚动保存有界JSONL日志：2 MiB主文件及2个备份，包含进程、通道、采样计数、心率、质量、状态转换及分类/拒绝累计数。
- 按明确的一次性请求保存验证原始数据，默认不持续录制。

## 演示预警规则

参数在`board/inference/monitor_config.json`，不是经过临床验证的诊断界限。

| 条件 | 行为 |
|---|---|
| 心率低于50或高于120，质量合格且持续10秒 | 显示低于下限/超过上限 |
| 回到设定范围并持续5秒 | 解除心率预警 |
| 连续3拍质量合格、分类概率≥0.90、类别为A/F/L/R/S/V | 显示连续非N分类，保持8秒 |
| 单次非N、低置信度、N或`|` | 不累计连续非N预警 |
| 质量差、结果过期、无可靠RR、输入故障 | 心率为空，暂停心率及分类预警 |

质量合格是本项目工程规则的判定，不代表所有伪迹均已排除；“检查电极”不是ADS1292硬件导联脱落检测。电极运动伪迹可能模拟异常心拍，因此没有把一次分类直接当作异常结论。参考：[PhysioNet噪声压力测试数据库说明](https://physionet.org/content/nstdb/1.0.0/)。本次未运行该数据库的完整验证集。

## 固件及软件验证

- ECG5 ABI `0x45434735`；状态栏窗口`0xa000..0xaa00`，640列，每列16位竖向位图和2位颜色。
- 波形、移动标签和状态栏共用帧缓冲切换，在垂直消隐同时提交。
- 时序WNS +0.009 ns、WHS +0.006 ns，无失败端点；LUT 15,578、FF 20,463、BRAM Tile 60、DSP 57。
- RTL仿真通过状态栏位图/颜色、独立缓存、地址边界、待提交写保护、逐拍字形、SPI/FIFO及按钮回归。
- 软件测试通过：60次/分合成心拍、两段优选真实记录、平直/饱和/强工频拒绝、持续阈值及恢复、连续分类触发、重复消息去重、`|`/低置信度/孤立分类不触发、过期结果清空、采集文件完整性。
- 同一FP32权重的49拍板上分类仍49/49匹配PyTorch，最大logit误差0.000002384。
- 将DMA输出显式复制为普通NumPy数组，避免PynqBuffer子类及BO元数据进入后处理；在清理前清除异常帧引用。修复后该49拍测试平均约120 ms，前三拍纯ARM对比约1.51倍速度；只是这项对比的测量，不能推广到所有模型或框架。

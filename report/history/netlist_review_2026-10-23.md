# 采集板与隔离板网表检查

> 第一版历史检查。用户已更新网表，四个电源／去耦错误在第二版修正；最新结果及仅面向PYNQ的最小修改见[第二版复查](netlist_review_2026-10-23_v2.md)。不要将下文第一版供电结论当作当前状态。

检查日期：2026-10-23。输入为 `采集板/ADS1292_2026-10-23.txt`、`隔离板/spi隔离_2026-10-23.txt`，并对照现有Pmod A XDC、STM32源码、TI ADS129x Rev.C及ISO776x Rev.H手册。

结论：**当前隔离板网表不应直接投板／上电验收，至少先修正四个电源／去耦网络，并取消跨隔离边界的地、电源及旧STM32接口连接。** 用户已确认U6与H5同号直接对插，因此下文整排插接导致的地线旁路和总线并接是确定问题。原始网表未被改写，本报告中的修改需在原理图实施后重新导出网表确认。

## 1. 确定错误：四个电源脚隔着电容接电源

隔离板原始网络为：

```text
$1N11 : U1.1  C1.1
$1N10 : U1.16 C2.1
$1N15 : U2.1  C3.1
$1N17 : U2.16 C4.1
3V3A  : C1.2 C3.2 U6.9
3V3D  : C2.2 C4.2 U5.11 U5.12 U6.10
```

ISO7763的1脚是VCC1，16脚是VCC2。每个电源脚只与一个电容端子组成独立网络，没有直接接到电源；电容另一端反而接电源。这形成串联电容供电，不是电源对地去耦，无法提供正常直流工作电流。

**按本次网表实际采用的两侧定义修改**（和此前建议示例相反，但本身允许）：Side1＝采集侧3V3A/GNDA；Side2＝主机侧3V3D/GNDD。

| 网络 | 应直接连接的节点 |
|---|---|
| 3V3A | U1.1、U2.1、C1.1、C3.1、采集侧供电入口U6.9 |
| GNDA | U1.8、U2.8、C1.2、C3.2、采集侧地U6.1 |
| 3V3D | U1.16、U2.16、C2.1、C4.1、Pmod侧供电 |
| GNDD | U1.9、U2.9、C2.2、C4.2、Pmod侧地 |

电容仍用现有四个100nF，各靠近相应VCC／GND脚。不应在原串接电容两端简单加短路后保留原网络：应将电容另一端真正改接本侧地。

## 2. 已确认的严重问题：整排对插会把隔离地短接

两份网表分别明确：

```text
隔离板：U6.1 = GNDA；U6.2 = GNDD
采集板：H5.1 = GND；H5.2 = GND（同一网络）
```

**只要U6.n对应H5.n并且1、2脚都接通，就形成**：

```text
隔离板GNDA → U6.1 → H5.1 → 采集板GND → H5.2 → U6.2 → 隔离板GNDD
```

所以隔离板自身GNDA/GNDD虽分开，组合后仍被连接器旁路。用户已确认同号直接对插，设计连接中的旁路已确定；尚未实际通电或测量。

采集板STM32与ADS1292共享GND并不自动构成采集板内部错误；问题是不能把这个共同地同时接到新隔离器的HOST地。原板内 `GND1` 是USB侧的另一个地名，也不是ISO芯片的GND1脚含义，必须按网络边界区分。

## 3. 全针插接还会并联两个主机及两路3.3V电源

同号全接时，隔离板HOST网络还接回原STM32：

| 信号 | 隔离板HOST网络／U6 | 采集板H5同号脚连接 |
|---|---|---|
| DRDYD | U6.4 | STM32 PA0，输入 |
| SCLKD | U6.6 | STM32 PA5，SPI时钟输出 |
| DIND | U6.8 | STM32 PA7，SPI MOSI输出 |
| DOUTD | U6.12 | STM32 PA6，SPI输入 |
| CSD | U6.14 | STM32 PA4，推挽输出 |
| STARTD | U6.16 | STM32 PB0，推挽输出 |
| RESETD | U6.18 | STM32 PB1，推挽输出 |
| 3V3D | U6.10 | 采集板3.3V1，STM32侧电源 |

现有固件会实际配置这些输出，因此PYNQ与STM32并接后可能争用总线。即使暂时停用STM32程序，GND旁路和电源并联仍未解决；不能仅靠“不运行STM32”验收通过。也不应把PYNQ 3.3V与原板3.3V1直接并联为两个电源源端。

### 针对PYNQ的建议改法

若保留现有采集板不改，隔离板U6只连接H5的**奇数脚**：

| U6/H5同号脚 | 接采集侧 |
|---:|---|
| 1 | GND |
| 3 | DRDY |
| 5 | SCLK |
| 7 | DIN |
| 9 | ADC数字3.3V（采集板3.3VD） |
| 11 | DOUT |
| 13 | CS |
| 15 | START |
| 17 | PWDN/RESET |

**隔离板U6的2、4、6、8、10、12、14、16、18脚全部不接网络**，不能再把HOST地、电源或信号送回这些针。主机侧只从Pmod进入，原STM32留在采集侧且不与新SPI通路相连。若希望保留STM32／PYNQ两种工作方式，需要另做完整的模式选择，而非默认全针接通。

## 4. 七根信号的隔离方向：当前连接正确

本次网表把Side1放采集侧、Side2放PYNQ侧。ISO7763是3＋3双向，所以和先前示例采用不同侧别及通道字母仍可以正确工作，不要求照搬旧表。

| 信号 | 当前实际通道 | 输入→输出 | 方向 |
|---|---|---|---|
| DRDY | U1.A | 采集DRDY→U1.2→U1.15→DRDYD | ADC→PYNQ |
| DOUT | U1.B | 采集DOUT→U1.3→U1.14→DOUTD | ADC→PYNQ |
| DIN | U1.D | PYNQ DIND→U1.12→U1.5→DIN | PYNQ→ADC |
| SCLK | U1.E | PYNQ SCLKD→U1.11→U1.6→SCLK | PYNQ→ADC |
| CS | U1.F | PYNQ CSD→U1.10→U1.7→CS | PYNQ→ADC |
| START | U2.D | PYNQ STARTD→U2.12→U2.5→START | PYNQ→ADC |
| RESET | U2.E | PYNQ RESETD→U2.11→U2.6→PWDN/RESET | PYNQ→ADC |

输出未见直接并接。以上结论以U1/U2实际型号为ISO7763DWR、器件库脚号与手册一致为前提；导出BOM的Value仍为占位符，需补实际料号。

## 5. 空余输入应处理

在本次Side1=ADC、Side2=HOST定义下：

- U1.INC（4脚）接GNDA；对应OUTC（13脚）不接。
- U2.INA/INB/INC（2/3/4脚）接GNDA；对应OUTA/OUTB/OUTC（15/14/13脚）不接。
- U2.INF（10脚）接GNDD；对应OUTF（7脚）不接。

这些输入当前都没有网络，建议固定电平；不要把输出接地。默认高的ISO7763DWR也仍需考虑HOST失电时START变高的问题；新增采集侧门控／有效使能仍未体现在网表中。正常供电下主机输入偏置也尚未添加。

## 6. Pmod接口：必须确认CAD封装编号，不能按数字直接等同

隔离板U5使用的是2×6公头封装，当前网络采用一套交错编号：

| 信号 | 标准Pmod物理针号 | 当前CAD的U5焊盘号 |
|---|---:|---:|
| CS | 1 | 2 |
| DIN | 2 | 4 |
| DOUT | 3 | 6 |
| SCLK | 4 | 8 |
| GND | 5 | 10 |
| 3.3V | 6 | 12 |
| DRDY | 7 | 1 |
| START | 8 | 3 |
| RESET | 9 | 5 |
| 空置 | 10 | 7 |
| GND | 11 | 9 |

**只有封装插接后确实按本表对应，才与当前比特流一致。** 网表只有焊盘号、没有几何位置和插接视角，不能单独确认机械映射正确，也不能仅凭这里数字不同便断言接错。需要核对U5原理图库、PCB封装顶视图、1脚与实际PYNQ插座方向。

## 7. 采集板主时钟：现在有硬件依据了

ADS1292 U1.14（CLKSEL）和U1.23（DVDD）都接 `3.3VD`；U1.17（CLK）通过R25=10kΩ接GND。按TI时钟选择表，该网表选择**内部标称512kHz时钟**，不需要PYNQ另送ADC主时钟。旧STM32 CONFIG2=0xA0中CLK_EN=0，与CLK脚不输出内部时钟的配置一致。

此前没有原理图／网表，故只能保留CLKSEL未知；本条是新材料带来的结论更新，不是根据软件推断硬件。实板仍需与此网表一致，DRDY频率待实测。

ADC数字端的CS／DIN／SCLK／DOUT／DRDY／START／RESET脚号与ADS1292手册相符。当前RESET经100k下拉，START经100k下拉，CS经100k上拉，DOUT经100k上拉；供电修正后隔离器正常推挽输出会驱动这些网络，RESET仍应按程序主动执行规定脉冲。

## 9. 用户补充器件型号后的核查

### 采集板U6/U7：TPS7A2033PDBVR

按[TI TPS7A20手册 Figure 4-4](https://www.ti.com/lit/ds/symlink/tps7a20.pdf#page=4)，DBV五脚为1=IN、2=GND、3=EN、4=NC、5=OUT。

- 两颗1、3脚均接+5V，2脚接GND，4脚未接，5脚分别接3.3VD和3.3V1，数字连线符合器件脚位。
- U6为ADS1292一侧电源，输出有C6=10µF／C15=1µF及100nF去耦；U7为STM32一侧3.3V1，输出有10µF与1µF等去耦。输入也有电容。仅从连接和值未发现类似隔离板的串联电容错误；稳定性、负载／温升、器件贴近程度需实板及PCB确认。
- 两颗均为非隔离LDO，不能将3.3VD与3.3V1的两路稳压本身当成电源隔离，两者现有地网均为GND。

### 采集板U8：ISO6521FDR

按[TI ISO6521手册 Figure 4-2／Table 4-1](https://www.ti.com.cn/cn/lit/ds/symlink/iso6521.pdf#page=3)，SOIC8为1=VCC1、2=OUTA、3=INB、4=GND1、5=GND2、6=OUTB、7=INA、8=VCC2。

- 1脚接STM32侧3.3V1，4脚接采集板GND；8脚接USB侧3V3，5脚接USB侧GND1，网表未把这两侧地直接合并。
- STM32 PA9/TX→U8.3/INB→U8.6/OUTB→USB侧RXD；USB侧TXD→U8.7/INA→U8.2/OUTA→STM32 PA10/RX。方向正确。
- 该器件是**功能隔离器**，不等于ISO7763DW的增强绝缘等级。保留USB通路时，不能仅凭新增SPI隔离器就宣称所有通向电脑的路径均满足同样的隔离等级。F后缀默认低，串口对端失电时输出状态也与通常UART空闲高不同，应在串口恢复／错误处理时考虑。

以上均是网表及型号层面的审查，不是整机安全或上电性能验证。

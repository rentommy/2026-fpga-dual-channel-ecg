## 1. 工具链该装哪些组件

**问题**：选题指南写"Vivado / Vitis 2026.1"，是要装两个吗？

**模型回答**：只装 Vivado。Vitis HLS 是 Vivado 安装包里的组件，
指南里的"Vitis"指的是独立的 Vitis IDE，那个用来写裸机程序和 PetaLinux 应用；
本项目 PS 侧全是 PYNQ 的 Python，不需要。

**结论**：安装器里选 `Vivado` → `Vivado ML Standard`，
勾 `Vivado Design Suite` + `Vitis HLS`，器件只勾 `SoCs` → `Zynq-7000`。
省下几十 GB。

**踩坑 ①**：安装器默认把 `Vitis Networking P4` 和 `Vitis Model Composer` 也勾上了。
前者是网络数据平面编程，后者要先装 MATLAB。都取消。
→ 写进 `skill/pitfalls.md`

**踩坑 ②**：AMD 改了版本命名。许可证网站上**没有** "Vivado ML Standard"，
免费档现在叫 **`Vivado Basic Tier License, Node Locked License`**
（同页还有 `Vivado Enterprise Tier License, 60 Day Evaluation`，说明是
Basic / Standard / Enterprise 三层 Tier 命名替代了旧的 WebPACK / ML Standard）。
模型第一次按旧名字指路，导致在列表里找不到，**是模型的过时知识造成的弯路**。
→ 写进 `skill/pitfalls.md`

## 2. sosfiltfilt 能不能直接搬到硬件

**提示词**：上位机用的是 `scipy.signal.sosfiltfilt`，硬件能照样实现吗？

**模型回答**：不能。`filtfilt` 是正反各滤一遍，反向那一遍需要先拿到整段数据，
实时流式硬件永远拿不到"未来的数据"。必须改成单向 `sosfilt`，
代价是引入群延迟。

**自我纠错轨迹**：模型一开始建议用"全局互相关 + 平移对齐"来验收
硬件输出和参考输出。实际跑出来相关系数只有 **0.589**，一度以为是实现错了。

追问后定位到：**单向 IIR 的相位失真随频率变化，不是一个固定延迟**，
所以无论平移多少个采样点都对不齐，全局相关系数在这里是**失效指标**。

改用"按 R 波对齐后的平均心拍模板相关"才反映真正在乎的波形形态，
并把验收指标改成 QRS 幅度误差 / 心率 / 检出心拍数 / 模型判读一致性。

**这是本阶段最有价值的一条经验**：验收指标选错会把正确的实现判成错的。
→ 写进 `skill/pitfalls.md` 和 `skill/README.md`

## 3. 定点系数格式

**提示词**：陷波器系数量化到 Q1.15 够吗？

**模型回答（第一版，错的）**：够，实测衰减只掉 2.7 dB。

**实际结果**：脚本直接断言失败 ——
`AssertionError: 系数超出 Q1.15 范围: [32096, -51932, 32096]`

**自我纠错**：Q1.15 = 1 符号位 + 15 小数位，范围 [−1, 1)。
而陷波器的 `b1 = a1 = −2cos(2π·50/500) = −1.585`，**超过 1**。
模型之前的"Q1.15 测试"用的是 `frac_bits=15` 的量化步长，
那在数学上正确，但**存储需要 17 位，不是 16 位**——
模型把"量化步长"和"存储位宽"混为一谈了。

**修正后的结论**：整数位必须留 2 位。最终选 **18 位存储**：
- 陷波器 Q2.16，FIR Q1.19
- 理由是 **DSP48E1 是 25×18 有符号乘法器，18 位是系数端口的原生宽度**，
  用 18 位不比 16 位多占资源，精度高 4 倍

**顺带发现一个数据陷阱**：Q=15 配 Q2.14（16 位）测出 −68.9 dB，
比 Q2.16（18 位）的 −61.9 dB 还好。这是舍入的偶然，换 Q=20/30 就反过来。
**按这种运气选格式会在参数变化时失效**，所以按工程理由（DSP48 端口宽度）选，
不按单点实测数字选。
→ 写进 `skill/fixed_point_helper.py` 的使用说明

## 4. 一阶高通压不住呼吸漂移

**问题**：移位式直流阻断零乘法器，很香，但够用吗？

**实测**：注入 2 mV / 0.2 Hz 呼吸漂移，
- 移位 k=7 单级（一阶）：残留 **0.559 mV**
- 原来的三阶巴特沃斯：残留 **0.118 mV**

单级比原方案差 4.7 倍，残留漂移接近 QRS 幅度的一半。

**追问后的解法**：**级联**。移位式每级仍然零乘法器，
级联 n 级就得到 n 阶，衰减 dB 相加：
- k=7 两级：0.171 mV（定稿）
- k=7 三级：0.052 mV，反超三阶巴特沃斯

没选三级是因为高通角频率抬高会在 QRS 前后产生过冲、压低 ST 段
（QRS 幅度误差从 +1.9% 涨到 +4.0%），ST 段在心电里有临床含义。
级数是编译期参数，实际佩戴漂移更大再改。

**这条的可复用之处**：`移位式一阶滤波器级联` 是一个通用手法 ——
用"级数"换"阶数"，全程不花乘法器。任何做定点 DSP 的题目都能用。
→ 写进 `skill/README.md`

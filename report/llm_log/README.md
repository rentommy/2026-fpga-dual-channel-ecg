## 引用时需要带上的修正

| 历史说法 | 后续证据与当前口径 |
|---|---|
| 344次乘法≈344时钟周期 | 优化后HLS为每时刻八通道合计1298周期；操作次数不能当调度周期 |
| 7.300ns对10ns有2.70ns时序余量 | HLS表中2.70ns列名为Uncertainty；136.99MHz仅估计频率。实际系统100MHz，以布线后slack为准 |
| open_component可以彻底解决路径问题 | 嵌套目录仍曾失败；后续通过工作目录与组件父目录一致的入口复现 |
| g++通过即可视为ap_int分支通过 | 精确位宽分支随后真实暴露类型歧义；两者验证范围不同 |
| 已计划将约束移入源码、重写入口 | 接手时旧入口仍在，单DSP结果依赖hls_fix.tcl／hls_export.tcl；不能按承诺认定已提交 |
| 各通道喂同一记录、输出相同即可证明无串扰 | 10-23补做不同输入、逐通道单独激励、不规则分块和复位测试，20项通过 |
| 348／30ms即端到端显示延迟 | 是滤波冲激峰值位置，不含采集、分块、DDR和显示开销 |
| HPD=1说明显示正常 | 无显示器时也读到1；真实画面必须现场确认 |

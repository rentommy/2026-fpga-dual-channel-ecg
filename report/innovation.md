# 选题背景与创新点

> 本文是设计报告"创新性"一节的底稿。
> 每条创新点都给出：**是什么 / 为什么是新的 / 实测收益 / 边界在哪**。
> §6 专门列出**我们不声称的东西**，§7 给出与基线的量化对比。

---

## 1. 选题背景：一次具体的失败

项目最初用上位机软件做心电预处理，滤波链是 `scipy` 的 `filtfilt` ——
前向跑一遍、反向再跑一遍，**零相位但非因果**，必须拿到未来的数据才能算当前点。

要把它搬到 FPGA 上实时运行，就只能用因果滤波。我们按嵌入式领域的标准做法
实现了**级联移位高通**（`acc += (x-acc)>>k`，零乘法器，k=7 两级），
结果心拍形态明显劣化。实测：

| | 零相位参考 | 级联移位 k=7×2 |
|---|---|---|
| T 波幅度 | 100% | **49%** |
| 逐拍 ST60 偏差 | — | **−0.089 / −0.126 mV** |
| 心拍形态相关 | 1.000 | 0.854 |

**ST 段压低 0.1 mV 是临床判读阈值**。一个系统性读低 0.09~0.13 mV 的滤波器，
会把正常心电判成 ST 压低 —— 这不是"精度差一点"，是会给出错误结论。

这就是选题的起点：**实时性与诊断精度在因果滤波下发生了真实冲突**，
而这个冲突在"把软件算法搬到硬件"时普遍存在，不是我们这一个工程的特例。

---

## 2. 前人做过什么

基线漂移抑制是心电信号处理里最老的问题之一，已有做法大致分五类：

| 做法 | 特点 | 我们的处理 |
|---|---|---|
| **级联移位/一阶 IIR 高通** | 嵌入式标准做法，零乘法器，资源最省 | **作为基线实现并量化其缺陷**（§1） |
| **滑动平均 / 滑动中值减基线** | 经典，实现简单 | 本方案的组成部分，但参数准则不同（创新点 3） |
| **锚点插值（等电位段 + 样条）** | 诊断级精度，Meyer & Keiser 一类方法 | **实现并实测**：需要下一个锚点，约一拍延迟；零延迟外推版失败（§5） |
| **自适应滤波（LMS 等）** | 文献常见 | **实现并实测**：权重不收敛，电极脱落时放大 5.5 倍（§5） |
| **零相位双向滤波（filtfilt）** | 离线黄金标准，非因果 | **作为参考基准**；分块实时版实测延迟 12 秒（§5） |

相关标准：

- **IEC 60601-2-25（诊断级心电）要求高通截止 0.05 Hz**，正是因为更高的截止频率
  会歪曲 ST 段
- **IEC 60601-2-27（监护级）允许 0.5 Hz**，但监护模式明确不用于 ST 分析
- 肌电假肢控制文献中可接受的控制延迟约 **100~125 ms**

> 提交前需核对以上标准条款号与文献出处的准确版本。

我们的级联移位基线等效截止频率是 **0.98 Hz**，属于监护级指标 ——
**用监护级的滤波器去做诊断级的 ST 测量，这是问题的根源**。

## 3. 我们发现的关键事实：是相位，不是幅度

直觉上"滤波削掉了低频成分，所以 ST 段变形了"。我们做了一个**判决性实验**
来检验这个归因：把**同一个幅度响应**分别以因果和零相位两种方式施加。

| 级数 | 心拍形态相关（因果） | 心拍形态相关（零相位） |
|---|---|---|
| 1 | 0.9553 | 0.9950 |
| 2 | 0.8550 | 0.9845 |
| 3 | 0.7311 | 0.9719 |

两者的残留漂移幅度几乎相同（1.683 vs 1.726 mV），**形态却天差地别**。

**结论：破坏心拍形态的是相位失真，不是幅度衰减。** 归因变了，解法也就变了 ——
不该去调幅度响应，该去修相位。

### 这件事有理论支撑，也有理论限制

因果 LTI 系统的幅度与相位**不独立**：最小相位系统下 `ln|H|` 与 `arg H`
是希尔伯特变换对（Bode 增益—相位关系）。一旦要求"0.5 Hz 以下衰减"，
带内相位就被锁死，**不能自由选择**。

唯一能改相位而不动幅度的是全通环节，而有用的全通环节就是**纯延迟**，
所需延迟按 `1/fc` 标度。

> **所以"低延迟 + 保形态 + 强去漂移"三者不可兼得，这是定理不是调参空间。**
> 我们用实测确认了这条边界：延迟 124~460 ms 区间内，逐拍 ST60 误差
> 的离散度只有 6%（0.0746~0.0794 mV，标准差口径、两段取较差者），
> 已经触到两段数据可分辨的底 —— 再细调无法判断好坏。

既然取舍不可消除，**就把它变成可配置的** —— 这是本方案的架构出发点。

## 4. 创新点

### 创新点 1：把"延迟"从固定代价变成每通道可配置的架构参数

**是什么**：每通道并行 `N_PATHS` 条滤波通路，共享前级，只差一个延迟量 `D`，
`D` 由 `DC_DELAY_CFG[ch][path]` 逐通道逐通路配置（上板可做成 AXI-Lite 寄存器）。

```
            ┌─ 延迟抽头 D=0   ─┐
x ─ 温和高通 ─ yg ─┤                ├─ 减 lp ─ 陷波 ─ FIR ─ 30 ms  → 显示/报警/闭环
         │      └─ 延迟抽头 D=159 ─┘                      └─ 348 ms → ST测量/存档/推理
         └─ 矩形窗基线估计 lp（两条通路共享）
```

**为什么是新的**：常见做法是为整个系统选一个折中的延迟。而诊断要精度、
闭环要速度，**它们要的是同一份数据**。FPGA 可以让两条链在空间上并存，
**低延迟通路的延迟不因为诊断通路的存在而增加一个时钟** ——
这是空间并行相对时间复用的本质差别，CPU 上多跑一条链就是多一份时间，
而且中断与调度会引入抖动。

**实测收益**：增量成本 168 次乘法 = **一个 DSP48 的 0.084%**，
存储增量 840 bit/通道。两条通路的延迟实测精确命中 174 / 15 个采样点。

**边界**：通路数大于 2 时 BRAM 双读口不够，需按通道分时顺序读
（时钟预算 200,000 : 43，余量充足）。

---

### 创新点 2：零乘法器的线性相位高通，且延迟线与滑动窗共用 RAM

**是什么**：基线估计用矩形窗滑动求和（`sum += yg[n] - yg[n-L]`），
归一化用一次常数乘法代替除法。整个直流阻断级**只有 1 次乘法**。

**先说清楚这不是什么**：`z^-D - B(z)`（B 为矩形窗）展开后就是一个
长度 L 的线性相位 FIR 高通，滑动求和实现矩形窗也是教科书内容。
**我们没有发明新结构。**

**真正的贡献在两点**：

1. **识别出该用它** —— 一阶 IIR 的群延迟在 0.05~1 Hz 内变 **11.25 倍**，
   单一个 `D` 只能对齐一个频率；矩形窗的群延迟恒为 `(L-1)/2`，
   **所有频率一次对齐**。这个诊断把 `D` 从 200 降到 159 的同时精度还提高了。

   | 核 | 群延迟最小 | 最大 | 变化倍数 |
   |---|---|---|---|
   | 一阶 IIR k=8 | 22 | 249 | **11.25** |
   | 半高斯 σ=180 | 50 | 142 | 2.83 |
   | 矩形窗 L=400 | 199 | 200 | **1.00** |

2. **延迟线不单独开 RAM** —— 因为 `DC_DELAY_MAX`(192) < `DC_BOX_L`(320)，
   矩形窗历史里已经存着最近 320 个样本，延迟抽头**直接在这块 RAM 上多开
   一个读口**即可。而 BRAM 本来就是双端口的：一个口读滑出窗口的样本、
   一个口读延迟抽头，正好用满。每通道每通路省 4,608 bit，
   **通道数上限从约 260 提到约 520**。

**实测收益**：等效 320 抽头线性相位 FIR，**1 次乘法代替 320 次**；
整核 8 通道双通路占一个 DSP48 的 0.172%、4.1 块 BRAM18K（器件的 1.5%）。

**边界**：严格线性相位要求 `D=(L-1)/2` 为整数，即 L 取奇数。
L=320（偶）时不对称量是一个抽头的 `1/320`，实测影响
（L=321 比 L=320 好 0.0006 mV）**在噪声以内**，故未因此改参数。

---

### 创新点 3：`L ≈ 一个心拍` —— 一条可移植的参数准则

**是什么**：滑动窗长度必须接近或超过一个心动周期。

**为什么**：窗比一拍短时，窗里装着 QRS 和 T 波本身，
它们会把"基线"估计顶高，减完造成 **ST 系统性读低**。

| L | 窗长 | ST 偏差 调/验 |
|---|---|---|
| 256 | 512 ms | **−0.068 / −0.065 mV** |
| 320 | 640 ms | −0.028 / −0.036 mV |
| 512 | 1024 ms | −0.001 / −0.030 mV |

实测 RR 为 824 / 878 ms。**0.068 mV 的系统偏差已经是临床阈值的三分之二**，
而它完全不出现在常规的"心拍形态相关"指标里（见创新点 4）。

**一处修正（2026-10-20）**：这里原先写着"矩形窗的频响零点在 `fs/L` 的整数倍处，
取 `L ≈ RR` 正好把心率基频零陷掉"。**对定稿的 L=320 这句是错的。**
零点在 1.5625 Hz，心搏基频 1.217 Hz，该处增益 **0.262**，泄漏 26%。
零点正好压住基频要 `L ≈ 412`（增益 0.0025），但那个 L 随心率变，
而 `DC_BOX_L` 是编译期常量 —— 做成自适应就不再是 LTI。
**上表的收益是靠窗够长挣的，不是靠零点对齐挣的。**
详见 `design_phase2.md` §3.3。

**边界**：这条准则把 `L` 和心率绑定了。心率显著偏离标定范围（<50 或 >110 bpm）
时窗长与一拍的比例改变，ST 偏差会变大。**让 `L` 跟随 RR 是有依据的改进方向，
但尚未实现**。

---

### 创新点 4：用逐拍临床定义指标替代心拍模板相关

**是什么**：评价滤波器不看"平均心拍模板的相关系数"，而是**逐拍**测
`ST60 = y(J+60ms) − y(同一拍的 PQ 段)` 和 T 峰，与零相位参考逐拍配对比对。

**为什么是必要的**：心拍模板相关有两个盲点 ——

- **对漂移是盲的**：平均 70 多拍正好把基线漂移抵消掉
- **对幅度是盲的**：相关系数做了 L2 归一化

我们**被这两个盲点骗了四次**。最典型的一次：一个漂移高达 0.815 mV 的配置
拿到了全拍相关 0.9974、T 波 104% 的漂亮成绩，差点被定为方案。
换成逐拍指标后，三个候选的排名**整个翻转**：

| 方案 | 延迟 | 模板全拍相关 | 逐拍 ST60 误差 调/验 |
|---|---|---|---|
| 仅 0.039 Hz 高通 | 30 ms | **0.9974**（最好） | 0.136 / 0.194（**最差**） |
| 级联移位 k=7×2 | 30 ms | 0.8539 | 0.124 / 0.096 |
| 矩形窗 L=320 D=159 | 348 ms | 0.9592 | **0.077 / 0.058**（最好） |

**顺带发现**：以零相位 `filtfilt` 为参考时，"T 波占参考百分比"会超过 100%
（实测 104%）—— 因为参考自身的 0.5 Hz 高通也削了一点 T 波。
**参考不是幅度真值，只是相位真值**，所有百分比指标都要这样读。

**边界**：逐拍指标依赖 R 波检测与 PQ 段定位；心律失常或 P 波异常时
PQ 段未必等电位，该指标会失效。

## 5. 否证记录：被实测推翻的方案

这部分不是创新点，但我们认为它和创新点同等重要 ——
**十三轮探索里绝大多数方案是被自己的测量否掉的**，脚本与数据全部保留在
`sim/experiments/`，便于复核。

| 方案 | 否证它的测量 |
|---|---|
| 非线性自适应加权合并（双链路 + `w`） | 2×2 消融：把 `w` 钉死为 1，指标**一模一样** —— 整层是死重 |
| QRS 期间冻结基线更新 | 落回同一条"漂移 vs 形态"取舍曲线 |
| 门控期间按斜率外推基线 | 前提被否：冻结段平均只有 **1.6 个采样点**，形不成追赶瞬态 |
| 在线 LMS 预判基线 | 权重 30 秒内在 ±27~86% 间游走，**从未收敛**；电极脱落时输出放大 5.5 倍 |
| 固定 Wiener 预判（3 抽头拉开） | 有效但只买回 80 ms；m=200 时预测误差 33~49% |
| 锚点插值 + 零延迟外推 | 错拍 95 个（插值版需要下一个锚点，约一拍延迟） |
| 分块双向 filtfilt（10 s 窗 + 2 s 重叠） | 滤波质量**最好**（形态 0.9990），但延迟 12 秒 |
| 仅 0.05 Hz 高通（诊断级标准截止） | 形态近乎完美，但漂移 0.815 mV，**逐拍指标最差** |
| Savitzky-Golay 边缘外推 | 可证明赢不了：3 抽头 Wiener 已是同抽头集下的 MMSE 最优线性预测器 |
| 贝叶斯递归滤波 | 线性高斯卡尔曼 ≡ 递归 Wiener，同一个界；非线性模型版超出工期且会"编"出心拍 |
| 半高斯核 | 方向正确（群延迟平坦度），但矩形窗平坦度更好（1.00 vs 2.83）且更便宜 |

**最有价值的一条否证**：我们曾把"跳出取舍边界必须靠非线性/时变"写进记录，
后来被 2×2 消融推翻 —— 出路是**允许延迟**，而原先的搜索空间里
**延迟这个维度被默认排除了**。一个"某类方法必然做不到"的断言，
代价远大于一个错误的参数。

## 6. 我们不声称的东西

| 不声称 | 原因 |
|---|---|
| "发明了新的滤波结构" | `z^-D − B(z)` 就是线性相位 FIR，滑动求和是教科书内容 |
| "FPGA 算得快所以用 FPGA" | 8 通道双通路只占一个 DSP48 的 0.172%，速度完全不是瓶颈 |
| "单片机做不了" | 做得了，Cortex-M0 级别就够。FPGA 的理由在架构不在算力 |
| "用了 AI / 自适应滤波" | 定稿是**纯 LTI**。自适应方案测过并被否证 |
| "完全消除了基线漂移" | 残留 2 秒窗中位 0.039 / 0.022 mV，不是零 |
| "这是最优参数" | 延迟 124~460 ms 内逐拍 ST60 误差离散度仅 6%（0.0746~0.0794 mV），**差异在噪声内**，只能说"在可分辨范围内到顶" |
| "实时性好（30 ms）" | 只有低延迟通路是 30 ms，诊断通路是 348 ms，且 ST 测量必须走诊断通路 |

### 证据基础的保留

1. **两段 60 秒，一个被试**，全部结论建立在 120 秒数据上
2. **"验证段"已不是留出集** —— 调参中被反复查看并据以选参，存在选择泄漏
3. **参考基准不是真值** —— 形态指标量的是对 `filtfilt` 的相似度，不是临床正确性
4. 部分参数组合出现 **P 段相关塌陷**（0.65 / 0.38 / −0.55），原因未查清
5. **无电极脱落检测** —— 实测脱落时输出冲到 270 mV（QRS 的 234 倍），
   目前没有任何机制识别

## 7. 与基线的量化对比

口径统一：跳过前 543 点热身，逐拍指标按临床定义，参考为零相位 `filtfilt`。

| 方案 | 延迟 | 典型漂移 调/验 | ST60 总误差 调/验 | T 峰总误差 调/验 |
|---|---|---|---|---|
| **基线**：级联移位 k=7×2 | 30 ms | 0.150 / 0.076 | 0.1081 / 0.1563 | 0.2273 / 0.2643 |
| 本方案 低延迟通路 D=0 | 30 ms | 0.276 / 0.130 | 0.0852 / 0.0898 | 0.1447 / 0.1670 |
| 本方案 诊断通路 D=159 | 348 ms | **0.039 / 0.022** | **0.0559 / 0.0688** | **0.0927 / 0.1152** |

单位 mV。总误差 = √(偏差² + 标准差²)。

**诊断通路对基线：ST 误差好 1.9~2.3 倍，T 波好 2.3~2.5 倍，漂移好 3.5~3.8 倍**，
代价是延迟从 30 ms 增至 348 ms，乘法从 21 次增至 22 次。

**低延迟通路不是单纯改进**：同样 30 ms 下 ST/T 好 1.3~1.7 倍，
但基线平整度更差（0.276 对 0.150）。两者是不同取舍。

### 资源

| | 本方案（8 通道双通路） |
|---|---|
| 乘法次数 / 采样周期 | 344（占一个 DSP48 的 **0.172%**） |
| BRAM | 75,424 bit = **4.1 块 BRAM18K**（器件的 1.5%） |
| 乘法器实例 | **1**（时分复用） |
| 通道数上限 | 算力约 4,650；**BRAM 约 520**（瓶颈在存储） |

### 定点实现与浮点参考的一致性

C 仿真逐点比对 30034 点：**最大偏差 3.3 码（0.158 µV），RMS 0.698 码（0.034 µV）**。
量化误差比 ST 测量误差（55.9 µV）小两个数量级。

## 8. 过程本身

`report/llm_log/` 记录了与大模型协作的全过程，含 **30 条编号的自我纠错**，
每条写明：错在哪、被什么测量发现、造成什么后果。其中值得报告引用的有三条：

- **同一个盲点踩了四次**（心拍模板平均抵消漂移）—— 前三次之后还专门加了
  一列指标去暴露它，第四次照样踩。**知道坑在哪，和决策时真的去用那条规则，
  是两回事。**
- **一次错误的机理归因消耗了一整轮设计** —— 模型把 ST-T 损伤归因为
  "门控追赶瞬态"，据此设计的改进方案在实测后发现前提根本不存在。
- **测试平台抓出了"黄金参考本身错了"** —— 参考实现用了硬件做不到的算法
  （窗未填满时按实际点数平均，而硬件没有除法器）。
  这正是测试平台该抓的东西：**它的价值不在确认已知正确的东西。**

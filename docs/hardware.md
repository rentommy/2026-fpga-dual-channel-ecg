# 硬件与运行接口

板卡PYNQ-Z2，器件XC7Z020CLG400-1，处理时钟100MHz，视频640x480。采集前端ADS1292，两输入、24位，配置500Hz，数字侧3.3V。采集板与开发板之间使用ISO7763隔离SPI。原始原理图/PCB和网表保留在工作站采集板/隔离板目录，本公共候选暂不重复发布器件数据手册。

| 信号 | FPGA封装引脚 |
|---|---|
| CS_N | Y18 |
| DIN / 主机MOSI | Y19 |
| DOUT / 主机MISO | Y16 |
| SCLK | Y17 |
| DRDY_N | U18 |
| START | U19 |
| PWDN/RESET_N | W18 |
| SW0 | M20 |

以上是FPGA封装坐标，不是Pmod物理针号；不能按字母数字直接当排针序号接线。约束以board/ads1292_pmoda.xdc及dual_view.xdc为准。Pmod物理编号仍应结合板卡丝印、官方板图和接口朝向核查。隔离两侧的地与供电必须按隔离设计处理。

本项目人体采集使用电池供电、断开采集侧充电/调试线，并经已安装的隔离板连接。竞赛原型不等于医疗级安全认证。

控制ABI ECG6=0x45434736，采集/视频0x40010000、滤波0x40000000、卷积0x40020000。SW0稳定状态位于0x40 bit0。SPI临时降低至250kHz作为供电故障排查对照，ADC采样率仍为500Hz。用户后来确认故障来自反复断电。

尚缺：实际使用板卡版本的原理图、PCB、BOM、连接器朝向图统一归档；不能将较新的未制作PCB设计当作当前已测试硬件。
